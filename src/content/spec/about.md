# 關於 Zebrafish

歡迎來到 Zebrafish，一個記錄技術筆記、學習過程與生活想法的個人博客。

保持好奇，讓想法自由游動。希望這裡能成為整理思考、分享發現，也讓讀者找到靈感的地方。

## 從這裡開始

- **[文章探索](/archive/)**：按關鍵字、分類或標籤尋找文章，也能切換排序。
- **[稍後閱讀](/archive/?saved=true)**：收藏感興趣的文章。收藏只儲存在目前的瀏覽器，不需要帳號，也不會上傳到伺服器。
- **[GitHub](https://github.com/zebrafishgod)**：查看程式與專案。

## 閱讀方式

按下搜尋按鈕或使用 **Ctrl / ⌘ + K** 尋找內容。文章頁提供字級調整、專注模式、目錄與連結複製；閱讀偏好會儲存在本機。

目前保留了 Fuwari 的 Markdown 與功能示範文章，方便了解本站支援的內容格式。

## 關於這個網站

本站以 [Astro](https://astro.build/) 建構，基於 [Fuwari](https://github.com/saicaca/fuwari) 主題，使用 Pagefind 提供靜態全文搜尋。網站原始碼可在 [GitHub 倉庫](https://github.com/zebrafishgod/zebrafish-fuwariblog) 查看。

文章授權以各文章頁尾標示為準；第三方圖片與引用內容的權利歸原作者所有。
