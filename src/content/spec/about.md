# 关于 Zebrafish

欢迎来到 Zebrafish，一个记录技术笔记、学习过程与生活想法的个人博客。

保持好奇，让想法自由游动。希望这里能成为整理思考、分享发现，也让读者找到灵感的地方。

## 从这里开始

- **[文章探索](/archive/)**：按关键词、分类或标签寻找文章，也能切换排序。
- **[稍后阅读](/archive/?saved=true)**：收藏感兴趣的文章。收藏只存储在当前浏览器，不需要账号，也不会上传到服务器。
- **[GitHub](https://github.com/zebrafishgod)**：查看程序与项目。

## 阅读方式

点击搜索按钮或使用 **Ctrl / ⌘ + K** 寻找内容。文章页提供字号调整、专注模式、目录与链接复制；阅读偏好会存储在本地。

当前保留了 Fuwari 的 Markdown 与功能示范文章，方便了解本站支持的内容格式。

## 关于這个网站

本站以 [Astro](https://astro.build/) 构建，基于 [Fuwari](https://github.com/saicaca/fuwari) 主题，使用 Pagefind 提供静态全文搜索。网站源代码可在 [GitHub 仓库](https://github.com/zebrafishgod/zebrafish-fuwariblog) 查看。

文章授权以各文章页脚标示为准；第三方图片与引用内容的权利归原作者所有。
