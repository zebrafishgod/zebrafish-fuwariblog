# 第 1 章｜從第一個程式，到能自己安排流程


本章要解決的問題是：**怎樣把一句生活需求，變成電腦可以一步一步執行的指令？** 學完應能畫出「輸入 → 資料 → 條件 → 重複 → 輸出」，並寫成小程式。

## 1. 電腦與 Python：各自負責什麼

可以把一次執行理解成以下流程：你在編輯器寫文字 → 存成 `.py` → Python 解釋器讀取程式 → 作業系統協調硬體完成工作。

| 名詞 | 白話解釋 | 你需要做到的事 |
|---|---|---|
| CPU | 執行計算與指令 | 知道程式的計算要消耗時間 |
| 記憶體 RAM | 保存正在使用的資料 | 知道程式結束後，普通變數不會自動存檔 |
| 硬碟／SSD | 長期保存檔案 | 知道需要寫檔才能保留資料 |
| 作業系統 | 管理程式、記憶體、檔案等資源 | 分清程式與系統，不把 Windows 指令當 Python 語法 |
| 解釋器 | 讓 Python 程式運行的工具 | 能確認自己使用的是 Python 3 |
| 編輯器／IDE | 寫程式、運行和找錯的工具 | PyCharm 是工具，Python 是語言與運行環境 |
| PATH | 系統尋找可執行程式的目錄清單 | 能在終端機找到正確的 Python |

Python 常被稱為解釋型語言；以常用的 CPython 而言，原始碼通常先編譯成位元組碼，再由虛擬機執行。入門時先掌握「誰在執行我的檔案」，不用先鑽研底層。

64 位元與 32 位元描述硬體／軟體架構的一部分，會影響可用記憶體等限制；不是「每行 Python 一次能寫幾個數字」。跨平台表示相同 Python 程式經常能在不同系統運行，但路徑、系統命令及某些套件仍有差異。

### 第一次運行

建立 `hello.py`，內容如下：

```python
print("你好，Python！")
# 輸出：你好，Python！
# 說明：print 把文字顯示在畫面；引號屬於語法，畫面上不會連同引號一起顯示。
```

在該檔案所在目錄，用終端機執行以下命令。這是終端機命令，不要貼進 `.py`：

```text
python --version
python hello.py
```

Windows 若使用 Python Launcher，也可能使用 `py -3 hello.py`。重點是 IDE 與終端機選到同一個 Python 3。切換工作目錄與讀寫檔案的關係，會在第 2 章講解。

互動視窗中直接輸入一個表達式，可能自動顯示結果；寫進 `.py` 時，要用 `print()` 才會主動顯示。不要把互動視窗的 `>>>` 複製進程式。

### 註解與縮排

`#` 後面是註解。三引號建立的是多行字串；放在函式、模組等特定位置可成為文件字串，不應把它當成真正的「多行註解符號」。程式區塊使用一致縮排，通常每層 4 個空格。

## 2. 變數：名稱綁定到物件

初學時可以說變數「保存資料」，但遇到共享列表時，應使用更準確的想法：**名稱指向物件；賦值會建立或更改這個關係。**

```python
price = 8
quantity = 3
total = price * quantity
quantity = 5
print(total)
print(price * quantity)
# 輸出：第一行 24；第二行 40。
# 說明：total 保存先前那次計算的結果，不會因為 quantity 後來改變而自動重新計算。
```

| 執行後 | price | quantity | total |
|---|---:|---:|---:|
| 算出 total | 8 | 3 | 24 |
| 改 quantity | 8 | 5 | 24 |

名稱使用 `snake_case`，例如 `product_count`。不能用數字開頭，不能用 `class` 等關鍵字。`MAX_RETRY = 3` 的大寫只是「請勿任意修改」的慣例，Python 並未因此禁止重新賦值。

```python
value = 10
print(type(value).__name__)
value = "10"
print(type(value).__name__)
print(value + "2")
# 輸出：依次為 int、str、102。
# 說明：物件有類型；同一個名称之後可以綁定不同類型的物件。字串相加是拼接。
```

`type(value)` 查看類型。`id(value)` 取得物件在生命期內的身份識別數值；不要背它的具體數字，也不要把它當成跨次運行不變的編號。

## 3. 常見類型：先問資料代表什麼

| 類型 | 例子 | 常用來表示 |
|---|---|---|
| `int` | `3`、`-2` | 數量、次數、以「分」計的金額 |
| `float` | `1.75` | 測量值、近似小數 |
| `str` | `"P001"` | 名稱、商品編號、使用者輸入 |
| `bool` | `True`、`False` | 是否存在、是否成功 |
| `NoneType` | `None` | 尚無資料／沒有結果，與數字 0 不同 |
| `list` | `[70, 80, 90]` | 有順序的多筆資料 |
| `dict` | `{"name": "茶", "stock": 8}` | 一筆有欄位的資料，或按鍵查找的資料表 |

列表和字典本章先用於理解資料，第 2 章會完整講它們的操作。

### `==` 與 `is`

```python
a = [1, 2]
b = a
c = [1, 2]
print(a == c)
print(a is c)
print(a is b)
b.append(3)
print(a)
print(c)
# 輸出：依次為 True、False、True、[1, 2, 3]、[1, 2]。
# 說明：== 比較值；is 比較是否同一物件。b 和 a 共用一個列表，因此修改可被兩者看到。
```

判斷使用者輸入是不是 `"q"` 要用 `==`；判斷是否為空結果常用 `is None`。不要依賴小整數或短字串的共用細節來推導 `is` 的結果。

`str`、`int` 是不可變物件；列表、字典是可變物件。「重新賦值」與「修改同一物件」要分開。記憶體通常由 Python 管理；CPython 使用引用計數等機制，並有循環垃圾回收。循環引用不代表一定永遠無法回收。本階段不需要手動釋放每個普通變數。

第37–38集提到的「標記清除／分代」可以先理解為：沿仍可使用的引用關係判斷哪些物件還能到達，辨認只在圈內互相引用、但外界已無法使用的垃圾；並利用物件存活時間等資訊安排檢查。具體世代與策略會因Python實作及版本改變，不需要把某一版本的數字背成語言規則。`del name` 刪除的是名稱綁定，若別處仍引用該物件，物件仍可存在。

## 4. `input()` 收到的一律是字串

```python
raw_quantity = "3"  # 先模擬 input() 回傳，方便你直接執行。
print(raw_quantity * 2)
quantity = int(raw_quantity)
print(quantity * 2)
# 輸出：第一行 33；第二行 6。
# 說明：轉換前是文字重複；轉換後才是數值乘法。int 不會修改原本的字串。
```

真正互動時：

```python
name = input("你的名字：")
print(f"你好，{name}！")
# 輸出：先顯示「你的名字：」；假設輸入 小林，之後顯示「你好，小林！」。
# 說明：input 會等待使用者輸入；f-string 把大括號中的表達式結果放入文字。
```

`int("3")` 成功；`int("3.5")` 或 `int("abc")` 會引發 `ValueError`。遇到不合法輸入怎樣繼續運行，請讀 [例外處理補充](bridge-errors-testing.md)。第 40 集的 `raw_input()` 屬於 Python 2；本套筆記統一用 Python 3 的 `input()`。

### 格式化顯示

```python
total = 25 / 2
print("總額：%.2f" % total)
print("總額：{:.2f}".format(total))
print(f"總額：{total:.2f}")
# 輸出：三行都是 總額：12.50。
# 說明：三種寫法都能顯示兩位小數，日常优先掌握 f-string；格式化不會改變 total 的值。
```

浮點數是近似表示。練習電商金額時，使用整數「分」能避免累加小數的誤差；不是說加上 `:.2f` 就使內部計算精確了。

## 5. 運算：先算什麼，再比什麼

```python
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)
print(-7 // 2)
# 輸出：依次為 3.5、3、1、8、-4。
# 說明：/ 是除法；// 向負無窮方向取整；% 是餘數；** 是次方。
```

比較運算有 `== != < <= > >=`。容易搞混的是 `=` 賦值與 `==` 比較。組合條件時使用括號讓意思清楚，尤其是 `and`、`or` 同時出現時。

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)
print("P001" in {"P001": "茶"})
print(not [])
print("" or "匿名")
print("hello" and 5)
# 輸出：依次為 True、True、True、匿名、5。
# 說明：字典的 in 預設檢查鍵；空容器是假值；and/or 會短路並返回某個運算元，不一定是bool。
```

`and` 左邊是假時不再算右邊；`or` 左邊是真時不再算右邊。`not` 的結果才一定是布林值。`0`、空字串、空容器、`None` 都可在條件中視為假。

## 6. 分支：一條規則翻譯成一個判斷

需求：「分數在 0–100；90 以上是 A，60 以上是 B，其餘 C。」先把無效資料排除，再由高到低判斷。

```python
score = 85
if score < 0 or score > 100:
    level = "無效"
elif score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"
print(level)
# 輸出：B。
# 說明：if/elif/else 這一組只走第一個成立的分支；85 不符合 >=90，卻符合 >=60。
```

三個獨立 `if` 會各自判斷；一組 `if/elif` 只選一條路。若先測 `>=60`，95 就可能先被分到 B。改完條件要測「邊界的前一個、恰好邊界、後一個」：例如 59、60、61。

## 7. 迴圈：狀態怎麼變，何時停止

### `while`：只要條件成立就繼續

```python
count = 1
total = 0
while count <= 3:
    total += count
    count += 1
print(total)
print(count)
# 輸出：第一行 6；第二行 4。
# 說明：先判斷再執行；最後一次把 count 變成4，下一次判斷失敗才離開。
```

| 進入本輪時 count | 加之前 total | 加之後 total | 更新後 count |
|---:|---:|---:|---:|
| 1 | 0 | 1 | 2 |
| 2 | 1 | 3 | 3 |
| 3 | 3 | 6 | 4 |

死迴圈常因條件永遠為真，且沒有改變它的狀態或 `break`。每個 `while` 都應能回答：「哪個變數正在變？何時結束？」

### `for`：逐一拿出資料

```python
for number in range(2, 7, 2):
    print(number)
# 輸出：分別顯示 2、4、6，每個數字一行。
# 說明：range(start, stop, step) 包含起點、不包含終點；此例步長為2。
```

`range(3)` 產生 0、1、2；`range(3, 0, -1)` 產生 3、2、1。步長不能為 0。`for` 可以逐一讀取字串、列表和字典，不只搭配 `range()`。

### `break`、`continue` 和迴圈的 `else`

```python
numbers = [1, 3, 4, 8]
for number in numbers:
    if number % 2 != 0:
        continue
    print(number)
    break
else:
    print("找不到偶數")
# 輸出：4。
# 說明：continue 跳到下一輪；break 結束本層迴圈；因為break離開，所以不執行else。
```

把列表改成 `[1, 3]`，會顯示「找不到偶數」。迴圈的 `else` 表示迴圈正常耗盡／條件變假而結束、沒有透過 `break` 跳出；不是「if 條件沒成立」的意思。`return` 或未處理的例外若直接離開，也不會走到這個 `else`。

在 `while` 中使用 `continue` 時，檢查是否跳過更新計數器，否則很容易一直處理同一狀態。

### 巢狀迴圈：外面走一次，裡面走一輪

```python
for row in range(1, 4):
    for col in range(row):
        print("*", end="")
    print()
# 輸出：三行依次是 *、**、***。
# 說明：end="" 不换行；每輪內層結束後，外層中的print()負責換行。
```

第一輪 `row=1` 印 1 個星號；第二輪印 2 個；第三輪印 3 個。`break` 只離開它所在的那一層迴圈。這能遷移到第 68 集的九九乘法表：行決定外層、列決定內層，不需要背整張表的程式。

## 8. 從生活需求到程式：完整示範

需求：「有三件商品，統計有庫存的商品數量，以及總庫存。」

先定義資料：每件商品有名稱和庫存。再定義規則：庫存大於 0 的商品才算有貨。最後定義結果：一個計數、一個總和。

```python
products = [
    {"name": "茶", "stock": 3},
    {"name": "水", "stock": 0},
    {"name": "牛奶", "stock": 2},
]
available_count = 0
total_stock = 0
for product in products:
    total_stock += product["stock"]
    if product["stock"] > 0:
        available_count += 1
print(f"有貨商品：{available_count} 種")
print(f"總庫存：{total_stock} 件")
# 輸出：有貨商品：2 種；下一行 總庫存：5 件。
# 說明：種類數和件數是兩件事，用不同變數表示，才能避免把需求混為一談。
```

遇到新題先寫四行：資料長什麼樣、有哪些操作、必須守住哪些規則、怎樣證明結果正確。再動手寫語法。

## 9. 自查、練習與通過標準

先合上上文回答：

1. 為什麼修改 `quantity` 不會自動重算 `total`？
2. `input()` 輸入 12 後得到的是哪種物件？
3. `==` 和 `is` 各在比較什麼？
4. `range(1, 5)` 的最後一個數字是多少？
5. 迴圈的 `else` 何時執行？
6. 為什麼電商金額不只靠 `:.2f` 來保證精確？

核對要點：1. 賦值時已算完；2. 字串；3. 值／身份；4. 4；5. 正常完成且未break；6. 格式化只改顯示，不改內部浮點值。

練習：在上面的庫存統計中，增加「缺貨商品名稱」與「庫存少於 3 的商品名稱」兩項結果。先手算，再寫程式；測空列表、全部缺貨、剛好 3 件三種情況。暫時不用函式也可以。

通過標準：能逐輪寫出變數的值，能解釋自己的分支與停止條件，並且改一條需求後能自行修改程式。接下來閱讀 [第 2 章：資料、文字與檔案](02-data-text-files.md)。
