# 第 1 章｜从第一个程序，到能自己安排流程


本章要解决的问题是：**怎样把一句生活需求，变成电脑可以一步一步执行的指令？** 学完应能画出「输入 → 数据 → 条件 → 重复 → 输出」，并写成小程序。

## 1. 电脑与 Python：各自负责什么

可以把一次执行理解成以下流程：你在编辑器写文字 → 存成 `.py` → Python 解释器读取程序 → 操作系统协调硬件完成工作。

| 名词 | 白话解释 | 你需要做到的事 |
|---|---|---|
| CPU | 执行计算与指令 | 知道程序的计算要消耗时间 |
| 内存 RAM | 保存正在使用的数据 | 知道程序结束后，普通变量不会自动存文件 |
| 硬盘／SSD | 长期保存文件 | 知道需要写文件才能保留数据 |
| 操作系统 | 管理程序、内存、文件等资源 | 分清程序与系统，不把 Windows 指令当 Python 语法 |
| 解释器 | 让 Python 程序运行的工具 | 能确认自己使用的是 Python 3 |
| 编辑器／IDE | 写程序、运行和找错的工具 | PyCharm 是工具，Python 是语言与运行环境 |
| PATH | 系统寻找可执行程序的目录列表 | 能在终端找到正确的 Python |

Python 常被称为解释型语言；以常用的 CPython 而言，源代码通常先编译成字节码，再由虚拟机执行。入门时先掌握「谁在执行我的文件」，不用先钻研底层。

64 位与 32 位描述硬件／软件架构的一部分，会影响可用内存等限制；不是「每行 Python 一次能写几个数字」。跨平台表示相同 Python 程序经常能在不同系统运行，但路径、系统命令及某些包仍有差异。

### 第一次运行

创建 `hello.py`，内容如下：

```python
print("你好，Python！")
# 输出：你好，Python！
# 说明：print 把文字显示在画面；引号属于语法，画面上不会连同引号一起显示。
```

在该文件所在目录，用终端执行以下命令。这是终端命令，不要贴进 `.py`：

```text
python --version
python hello.py
```

Windows 若使用 Python Launcher，也可能使用 `py -3 hello.py`。重点是 IDE 与终端选到同一个 Python 3。切换工作目录与读写文件的关系，会在第 2 章讲解。

互动视窗中直接输入一个表达式，可能自动显示结果；写进 `.py` 时，要用 `print()` 才会主动显示。不要把互动视窗的 `>>>` 复制程序。

### 注解与缩排

`#` 后面是注解。三引号创建的是多行字符串；放在函数、模块等特定位置可成为文档字符串，不应把它当成真正的「多行注解符号」。程序区块使用一致缩排，通常每层 4 个空格。

## 2. 变量：名称绑定到对象

初学时可以说变量「保存数据」，但遇到共享列表时，应使用更准确的想法：**名称指向对象；赋值会创建或更改这个关系。**

```python
price = 8
quantity = 3
total = price * quantity
quantity = 5
print(total)
print(price * quantity)
# 输出：第一行 24；第二行 40。
# 说明：total 保存先前那次计算的结果，不会因为 quantity 后来改变而自动重新计算。
```

| 执行后 | price | quantity | total |
|---|---:|---:|---:|
| 算出 total | 8 | 3 | 24 |
| 改 quantity | 8 | 5 | 24 |

名称使用 `snake_case`，例如 `product_count`。不能用数字开头，不能用 `class` 等关键字。`MAX_RETRY = 3` 的大写只是「请勿任意修改」的惯例，Python 并未因此禁止重新赋值。

```python
value = 10
print(type(value).__name__)
value = "10"
print(type(value).__name__)
print(value + "2")
# 输出：依次为 int、str、102。
# 说明：对象有类型；同一个名称之后可以绑定不同类型的对象。字符串相加是拼接。
```

`type(value)` 查看类型。`id(value)` 取得对象在生命期内的身份识别数值；不要背它的具体数字，也不要把它当成跨次运行不变的编号。

## 3. 常见类型：先问数据代表什么

| 类型 | 例子 | 常用来表示 |
|---|---|---|
| `int` | `3`、`-2` | 数量、次数、以「分」计的金额 |
| `float` | `1.75` | 测量值、近似小数 |
| `str` | `"P001"` | 名称、商品编号、用户输入 |
| `bool` | `True`、`False` | 是否存在、是否成功 |
| `NoneType` | `None` | 尚无数据／没有结果，与数字 0 不同 |
| `list` | `[70, 80, 90]` | 有顺序的多笔数据 |
| `dict` | `{"name": "茶", "stock": 8}` | 一笔有栏位的数据，或按键查找的数据表 |

列表和字典本章先用于理解数据，第 2 章会完整讲它们的操作。

### `==` 与 `is`

```python
a = [1, 2]
b = a
c = [1, 2]
print(a == c)
print(a is c)
print(a is b)
b.append(3)
print(a)
print(c)
# 输出：依次为 True、False、True、[1, 2, 3]、[1, 2]。
# 说明：== 比较值；is 比较是否同一对象。b 和 a 共用一个列表，因此修改可被两者看到。
```

判断用户输入是不是 `"q"` 要用 `==`；判断是否为空结果常用 `is None`。不要依赖小整数或短字符串的共用细节来推导 `is` 的结果。

`str`、`int` 是不可变对象；列表、字典是可变对象。「重新赋值」与「修改同一对象」要分开。内存通常由 Python 管理；CPython 使用引用计数等机制，并有循环垃圾回收。循环引用不代表一定永远无法回收。本阶段不需要手动释放每个普通变量。

第37–38集提到的「标记清除／分代」可以先理解为：沿仍可使用的引用关系判断哪些对象还能到达，辨认只在圈内互相引用、但外界已无法使用的垃圾；并利用对象存活时间等资讯安排检查。具体世代与策略会因Python实作及版本改变，不需要把某一版本的数字背成语言规则。`del name` 删除的是名称绑定，若别处仍引用该对象，对象仍可存在。

## 4. `input()` 收到的一律是字符串

```python
raw_quantity = "3"  # 先模拟 input() 返回，方便你直接执行。
print(raw_quantity * 2)
quantity = int(raw_quantity)
print(quantity * 2)
# 输出：第一行 33；第二行 6。
# 说明：转换前是文字重复；转换后才是数值乘法。int 不会修改原本的字符串。
```

真正互动时：

```python
name = input("你的名字：")
print(f"你好，{name}！")
# 输出：先显示「你的名字：」；假设输入 小林，之后显示「你好，小林！」。
# 说明：input 会等待用户输入；f-string 把大括号中的表达式结果放入文字。
```

`int("3")` 成功；`int("3.5")` 或 `int("abc")` 会引发 `ValueError`。遇到不合法输入怎样继续运行，请读 [异常处理补充](bridge-errors-testing.md)。第 40 集的 `raw_input()` 属于 Python 2；本套笔记统一用 Python 3 的 `input()`。

### 格式化显示

```python
total = 25 / 2
print("总额：%.2f" % total)
print("总额：{:.2f}".format(total))
print(f"总额：{total:.2f}")
# 输出：三行都是 总额：12.50。
# 说明：三种写法都能显示两位小数，日常优先掌握 f-string；格式化不会改变 total 的值。
```

浮点数是近似表示。练习电商金额时，使用整数「分」能避免累加小数的误差；不是说加上 `:.2f` 就使内部计算精确了。

## 5. 运算：先算什么，再比什么

```python
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)
print(-7 // 2)
# 输出：依次为 3.5、3、1、8、-4。
# 说明：/ 是除法；// 向负无穷方向取整；% 是余数；** 是次方。
```

比较运算有 `== != < <= > >=`。容易搞混的是 `=` 赋值与 `==` 比较。组合条件时使用括号让意思清楚，尤其是 `and`、`or` 同时出现时。

```python
age = 20
has_ticket = True
print(age >= 18 and has_ticket)
print("P001" in {"P001": "茶"})
print(not [])
print("" or "匿名")
print("hello" and 5)
# 输出：依次为 True、True、True、匿名、5。
# 说明：字典的 in 预设检查键；空容器是假值；and/or 会短路并返回某个运算元，不一定是bool。
```

`and` 左边是假时不再算右边；`or` 左边是真时不再算右边。`not` 的结果才一定是布尔值。`0`、空字符串、空容器、`None` 都可在条件中视为假。

## 6. 分支：一条规则翻译成一个判断

需求：「分数在 0–100；90 以上是 A，60 以上是 B，其余 C。」先把无效数据排除，再由高到低判断。

```python
score = 85
if score < 0 or score > 100:
    level = "无效"
elif score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"
print(level)
# 输出：B。
# 说明：if/elif/else 这一组只走第一个成立的分支；85 不符合 >=90，却符合 >=60。
```

三个独立 `if` 会各自判断；一组 `if/elif` 只选一条路。若先测 `>=60`，95 就可能先被分到 B。改完条件要测「边界的前一个、恰好边界、后一个」：例如 59、60、61。

## 7. 循环：状态怎么变，何时停止

### `while`：只要条件成立就继续

```python
count = 1
total = 0
while count <= 3:
    total += count
    count += 1
print(total)
print(count)
# 输出：第一行 6；第二行 4。
# 说明：先判断再执行；最后一次把 count 变成4，下一次判断失败才离开。
```

| 进入本轮时 count | 加之前 total | 加之后 total | 更新后 count |
|---:|---:|---:|---:|
| 1 | 0 | 1 | 2 |
| 2 | 1 | 3 | 3 |
| 3 | 3 | 6 | 4 |

死循环常因条件永远为真，且没有改变它的状态或 `break`。每个 `while` 都应能回答：「哪个变量正在变？何时结束？」

### `for`：逐一拿出数据

```python
for number in range(2, 7, 2):
    print(number)
# 输出：分别显示 2、4、6，每个数字一行。
# 说明：range(start, stop, step) 包含起点、不包含终点；此例步长为2。
```

`range(3)` 产生 0、1、2；`range(3, 0, -1)` 产生 3、2、1。步长不能为 0。`for` 可以逐一读取字符串、列表和字典，不只搭配 `range()`。

### `break`、`continue` 和循环的 `else`

```python
numbers = [1, 3, 4, 8]
for number in numbers:
    if number % 2 != 0:
        continue
    print(number)
    break
else:
    print("找不到偶数")
# 输出：4。
# 说明：continue 跳到下一轮；break 结束本层循环；因为break离开，所以不执行else。
```

把列表改成 `[1, 3]`，会显示「找不到偶数」。循环的 `else` 表示循环正常耗尽／条件变假而结束、没有透过 `break` 跳出；不是「if 条件没成立」的意思。`return` 或未处理的异常若直接离开，也不会走到这个 `else`。

在 `while` 中使用 `continue` 时，检查是否跳过更新计数器，否则很容易一直处理同一状态。

### 巢状循环：外面走一次，里面走一轮

```python
for row in range(1, 4):
    for col in range(row):
        print("*", end="")
    print()
# 输出：三行依次是 *、**、***。
# 说明：end="" 不换行；每轮内层结束后，外层中的print()负责换行。
```

第一轮 `row=1` 印 1 个星号；第二轮印 2 个；第三轮印 3 个。`break` 只离开它所在的那一层循环。这能迁移到第 68 集的九九乘法表：行决定外层、列决定内层，不需要背整张表的程序。

## 8. 从生活需求到程序：完整示范

需求：「有三件商品，统计有库存的商品数量，以及总库存。」

先定义数据：每件商品有名称和库存。再定义规则：库存大于 0 的商品才算有货。最后定义结果：一个计数、一个总和。

```python
products = [
    {"name": "茶", "stock": 3},
    {"name": "水", "stock": 0},
    {"name": "牛奶", "stock": 2},
]
available_count = 0
total_stock = 0
for product in products:
    total_stock += product["stock"]
    if product["stock"] > 0:
        available_count += 1
print(f"有货商品：{available_count} 种")
print(f"总库存：{total_stock} 件")
# 输出：有货商品：2 种；下一行 总库存：5 件。
# 说明：种类数和件数是两件事，用不同变量表示，才能避免把需求混为一谈。
```

遇到新题先写四行：数据长什么样、有哪些操作、必须守住哪些规则、怎样证明结果正确。再动手写语法。

## 9. 自查、练习与通过标准

先合上上文回答：

1. 为什么修改 `quantity` 不会自动重算 `total`？
2. `input()` 输入 12 后得到的是哪种对象？
3. `==` 和 `is` 各在比较什么？
4. `range(1, 5)` 的最后一个数字是多少？
5. 循环的 `else` 何时执行？
6. 为什么电商金额不只靠 `:.2f` 来保证精确？

核对要点：1. 赋值时已算完；2. 字符串；3. 值／身份；4. 4；5. 正常完成且未break；6. 格式化只改显示，不改内部浮点值。

练习：在上面的库存统计中，增加「缺货商品名称」与「库存少于 3 的商品名称」两项结果。先手算，再写程序；测空列表、全部缺货、刚好 3 件三种情况。暂时不用函数也可以。

通过标准：能逐轮写出变量的值，能解释自己的分支与停止条件，并且改一条需求后能自行修改程序。接下来阅读 [第 2 章：数据、文字与文件](02-data-text-files.md)。
