## 7.1 为什么需要函数

需要让一段代码**在多个地方使用**时，复制粘贴会带来三大问题：

1. **代码冗余**：大量重复代码，是低水平的实现方式
2. **可读性差**：代码组织结构混乱
3. **维护性差**：改一处功能，要同步修改几十处甚至上百处

**函数就是具备某一功能的工具**，使用原则是**先定义，后调用**。把功能写成函数后，100 个地方直接调用即可；以后修改只需改定义处，所有调用自动生效。
类比：函数像一台封装好的机器，投料（传参）就出成品（返回值），内部怎么运转不用每次重造。
```python
def print_line():
    print('-' * 20)

print_line()
print('登录成功')
print_line()
# 输出:
# --------------------
# 登录成功
# --------------------
```

## 7.2 函数定义与调用

### 7.2.1 定义语法

```text
def 函数名(参数1, 参数2, ...):
    """文档描述"""
    函数体
    return 值
```

**各部分说明**

| 部分 | 说明 | 是否必须 |
|---|---|---|
| `def` | 定义函数的关键字 | 必须 |
| 函数名 | 遵循变量命名规范，建议用动词（如 `upload_data`） | 必须 |
| 括号与参数 | 括号必须有，参数可选 | 括号必须 |
| 冒号 | 标记函数体开始 | 必须 |
| 文档描述 | 三引号说明功能、参数、返回值 | 可选 |
| 函数体 | 实现功能的代码，暂时不写用 `pass` 占位 | 必须 |
| `return` | 返回结果，不写默认返回 `None` | 可选 |

```python
def add(x, y):
    """计算两个数的和"""
    return x + y

print(add(1, 2))  # 输出: 3
```

### 7.2.2 定义与调用的本质

- **定义函数**：申请内存存放函数体代码，把内存地址绑定给函数名。**定义阶段只检测语法，不执行代码**。
- **调用函数**：通过函数名找到内存地址，加括号触发执行。
```python
def func():
    print(a)  # a未定义，但语法正确，定义阶段不报错

print('定义 func 没有报错')  # 输出: 定义 func 没有报错
# 只有执行 func() 时才会报 NameError: name 'a' is not defined
```


:::warning[注意]
“定义阶段只检测语法”有两层例外，别误以为定义时什么错都发现不了：
- **语法错误在定义阶段就会报**，如 `def func(:`。
- **`nonlocal` 绑定失败也会在定义阶段报 `SyntaxError`**（见 7.12），因为查找顺序必须在此刻确定。
而“变量未定义”这类错误要等到调用时才暴露。
:::

### 7.2.3 名字查找顺序以定义阶段为准

```python
x = 10

def func1():
    print(x)

def func2():
    x = 20
    func1()  # 在func2内部调用func1

func2()
# 输出: 10  而不是20
```

`func1` 定义在全局，局部没有 `x` 就去全局找，**根本看不到 `func2` 的局部**。**名字的查找顺序与调用位置无关**。
## 7.3 参数传递

### 7.3.1 形参与实参

- **形参**（Parameter）：定义时括号里的参数，相当于变量名
- **实参**（Argument）：调用时传入的值，相当于变量值

```python
def func(x, y):  # x、y 是形参
    print(x, y)

func(6, 8)  # 6、8 是实参  输出: 6 8
```

**绑定关系**：调用时把实参的内存地址绑定给形参，只在函数内部有效，调用结束自动解除。Python 中所有值的传递都是**内存地址的传递**。
### 7.3.2 位置参数

**位置形参**：按从左到右的顺序定义，调用时必须传值，多一个少一个都不行。
**位置实参**：按顺序与形参一一对应。
```python
def func(x, y, z):
    print(x, y, z)

func(1, 2, 3)  # 输出: 1 2 3     1→x, 2→y, 3→z
func(3, 2, 1)  # 输出: 3 2 1     3→x, 2→y, 1→z
```

### 7.3.3 关键字参数

**关键字实参**：以 `key=value` 形式传值，可以不按顺序。
```python
def func(x, y, z):
    print(x, y, z)

func(z=3, x=1, y=2)  # 输出: 1 2 3
```

**混用规则**：位置实参必须在关键字实参之前。
```python
func(1, 2, z=3)    # 正确
# func(1, z=3, 2)  # SyntaxError: positional argument follows keyword argument
# func(1, 2, y=3)  # TypeError: func() got multiple values for argument 'y'
```

## 7.4 默认参数

**默认形参**：定义时赋了默认值，调用时可以不传。
```python
def func(x, y=2):  # y是默认形参
    print(x, y)

func(1)     # 输出: 1 2
func(1, 3)  # 输出: 1 3
```

**定义规则**：默认形参必须放在位置形参之后。
### 7.4.1 默认值在定义阶段赋值

```python
a = 2

def func(x, y=a):  # 定义时 y 绑定了 2 的内存地址
    print(x, y)

a = 3
func(1)  # 输出: 1 2  而不是 1 3
```

### 7.4.2 默认值不要使用可变类型


:::warning[注意]
默认值只在**定义时创建一次**，多次调用会共用同一个对象。因此默认值不要设为列表、字典等可变类型。
:::

错误写法：

```python
def my_append(x, y, l=[]):  # 不规范
    l.append(x)
    l.append(y)
    print(l)

my_append(1, 2)  # 输出: [1, 2]
my_append(3, 4)  # 输出: [1, 2, 3, 4]  共用了同一个列表!
```

规范写法（用 `None` 占位，调用时再创建）：

```python
def my_append(x, y, l=None):
    if l is None:
        l = []
    l.append(x)
    l.append(y)
    print(l)

my_append(1, 2)  # 输出: [1, 2]
my_append(3, 4)  # 输出: [3, 4]
```

### 7.4.3 如何选择形参类型

- **值每次都不同** → 位置形参
- **值大多数时候固定** → 默认形参

例如 `open(file, mode='r')`：文件路径每次不同，用位置形参；模式多数情况是 `'r'`，用默认形参。
## 7.5 可变长参数

### 7.5.1 `*args`：收集多余的位置实参

用 `*` 接收多出来的位置实参，打包成**元组**。规范命名为 `args`。
```python
def func(*args):
    res = 0
    for i in args:
        res += i
    return res

print(func(1, 2))        # 输出: 3
print(func(1, 2, 3, 4))  # 输出: 10
```

### 7.5.2 `**kwargs`：收集多余的关键字实参

用 `**` 接收多出来的关键字实参，打包成**字典**。规范命名为 `kwargs`。
```python
def func(x, y, **kwargs):
    print(x, y, kwargs)

func(1, y=2, a=1, b=2, name='egon')
# 输出: 1 2 {'a': 1, 'b': 2, 'name': 'egon'}
```

### 7.5.3 实参中的 `*` 和 `**`：打散

**`*` 打散成位置实参**：

```python
def func(x, y, z):
    print(x, y, z)

func(*[1, 2, 3])  # 打散后相当于 func(1, 2, 3)  输出: 1 2 3
func(*'abc')      # 输出: a b c
```

**`**` 打散成关键字实参**：

```python
func(**{'x': 1, 'y': 2, 'z': 3})  # 相当于 func(x=1, y=2, z=3)  输出: 1 2 3
```


:::tip[技巧]
形参中的 `*` 和 `**` 是**打包**（多个值→一个元组/字典），实参中的 `*` 和 `**` 是**打散**（一个容器→多个值）。
:::

### 7.5.4 参数顺序规则

混用时的顺序：**位置形参 → 默认形参 → `*args` → `**kwargs`**

```python
def func(x, y=1, *args, **kwargs):
    print(x, y, args, kwargs)

func(1)                     # 输出: 1 1 () {}
func(1, 2, 3, 4, a=5, b=6)  # 输出: 1 2 (3, 4) {'a': 5, 'b': 6}
```

## 7.6 返回值

### 7.6.1 `return` 的作用

1. **立刻结束函数**，包括多层嵌套循环
2. **返回结果**给调用处

```python
def func():
    while True:
        while True:
            print('进入最里层')
            return  # 整个函数立刻结束

func()
print('函数已结束')
# 输出:
# 进入最里层
# 函数已结束
```

### 7.6.2 返回多个值

用逗号隔开，Python 自动打包成**元组**：

```python
def func():
    return 18, '梦泪', True

res = func()
print(res)        # 输出: (18, '梦泪', True)
print(type(res))  # 输出: <class 'tuple'>
```

### 7.6.3 函数调用的三种形式

```python
def add(x, y):
    return x + y

# 1. 语句形式:单纯调用,不使用返回值
add(6, 8)

# 2. 表达式形式:接收返回值或参与运算
s = add(6, 8)
s = add(6, 8) * 2

# 3. 作为参数传递(传的是上一次调用的返回值)
s = add(add(6, 8), 2)  # 先得到 14,再计算 14 + 2
```

### 7.6.4 参数完整演示

下面的示例综合展示了所有参数类型：

```python
def demo(a, b, c=3, *args, **kwargs):
    """
    a, b: 位置形参
    c: 默认形参
    *args: 可变长度位置参数
    **kwargs: 可变长度关键字参数
    """
    print(f'a={a}, b={b}, c={c}')
    print(f'args={args}')
    print(f'kwargs={kwargs}')

demo(1, 2)
# 输出:
# a=1, b=2, c=3
# args=()
# kwargs={}

demo(1, 2, 4, 5, 6, x=7, y=8)
# 输出:
# a=1, b=2, c=4
# args=(5, 6)
# kwargs={'x': 7, 'y': 8}

demo(1, b=2, x=10)
# 输出:
# a=1, b=2, c=3
# args=()
# kwargs={'x': 10}
```

## 7.7 参数原封不动转交

在学名称空间之前，先掌握 `*args, **kwargs` 最重要的应用——**参数原封不动转交**，这是函数部分的重中之重。
### 7.7.1 问题：一个函数的参数受另一个函数牵制

```python
def func1(x, y, z):
    print('func1:', x, y, z)

def func2(a, b, c):
    func1(a, b, c)

func2(1, 2, 3)  # 输出: func1: 1 2 3
```

如果 `func1` 增加一个参数 `d`，`func2` 就得跟着加形参，调用 `func2` 的地方也得多传一个值。**`func2` 的参数受 `func1` 牵制**，扩展不便。
### 7.7.2 解决：`*args, **kwargs` 原封不动转交

```python
def func1(x, y, z):
    print('func1:', x, y, z)

def func2(*args, **kwargs):
    func1(*args, **kwargs)  # 形参处收集,实参处打散

func2(1, 2, 3)    # 输出: func1: 1 2 3
func2(1, 2, z=3)  # 输出: func1: 1 2 3
```

**参数传递过程**：

1. `func2` 收到 `1, 2, 3` → `*args` 打包为 `(1, 2, 3)`，`**kwargs` 为 `{}`
2. 执行 `func1(*args, **kwargs)` → `*` 打散元组，`**` 打散字典
3. 相当于 `func1(1, 2, 3)`

给 `func2` 传的参数**原封不动地转交**给 `func1`。以后 `func1` 参数怎么变，`func2` 都不用改，调用 `func2` 时按 `func1` 的形参规则传参即可。

:::warning[注意]
这是**装饰器的核心机制**，必须熟练掌握，否则后面完全看不懂装饰器是怎么给原函数透传参数的。
:::

## 7.8 名称空间

### 7.8.1 Python 之禅

```python
import this  # 打印Python之禅
```

最后一句：`Namespaces are one honking great idea -- let's do more of those!`（名称空间是个绝妙的想法，我们应该多加利用）

### 7.8.2 名称空间与栈区

**名称空间**（Namespace）就是**存放名字的地方**，是对栈区中名字的分类：

- **内置名称空间**（Built-in）：存放 Python 内置的名字，如 `print`、`input`、`len`
- **全局名称空间**（Global）：存放文件内定义的名字（变量、函数、类），排除函数内部
- **局部名称空间**（Local）：存放函数内部定义的名字（包括形参）

三个名称空间相互独立，同名的名字放在不同空间互不冲突：

```python
x = 100

def func():
    x = 200  # 与全局x在不同名称空间
    print(x)

func()      # 输出: 200
print(x)    # 输出: 100
```

### 7.8.3 产生与销毁时机

| 名称空间 | 产生时机 | 销毁时机 |
|---|---|---|
| 内置 | 解释器启动时 | 解释器关闭时 |
| 全局 | 文件执行前 | 文件执行完毕 |
| 局部 | 函数调用时 | 函数调用结束 |

**加载顺序**：内置 → 全局 → 局部

每调用一次函数产生一个**新的**局部名称空间，所以局部名称空间可以有很多个。
## 7.9 LEGB 查找规则

### 7.9.1 查找顺序：局部 → 全局 → 内置

**大原则：从当前位置开始找。**

- 当前在**局部**：局部 → 全局 → 内置
- 当前在**全局**：全局 → 内置

```python
input = 1             # 全局

def func():
    input = '梦泪'   # 局部
    print(input)      # 当前在局部,先找局部

func()        # 输出: 梦泪
print(input)  # 当前在全局,先找全局  输出: 1
```

### 7.9.2 查找顺序以定义阶段为准

```python
x = 10

def func1():
    print(x)

def func2():
    x = 20
    func1()  # 在func2内部调用

func2()  # 输出: 10  而不是20
```

`func1` 定义在全局，局部没有 `x` 就去全局找，**看不到 `func2` 的局部**。查找顺序**与调用位置无关**，只由函数定义时所在的层级决定。
### 7.9.3 函数嵌套与 LEGB

在函数内部定义函数：

```python
input = 10            # 全局

def func1():
    input = 20        # func1的局部
    def func2():
        input = 30    # func2的局部
        print(input)
    func2()

func1()  # 输出: 30
```

逐层注释掉各层的 `input`，即可验证查找顺序：

```python
input = 10

def func1():
    input = 20
    def func2():
        # input = 30  注释掉
        print(input)  # func2局部没有,去func1的局部找 → 20
    func2()

func1()  # 输出: 20
```

**LEGB 四个字母**：

- **L**（Local）：本地，当前函数的局部
- **E**（Enclosing）：外层函数的局部
- **G**（Global）：全局
- **B**（Built-in）：内置

查找顺序：**L → E → G → B**

## 7.10 作用域

**作用域**（Scope）是按作用范围对名称空间的再分类：

- **全局作用域**：内置 + 全局，**全局存活、全局有效**
- **局部作用域**：局部，**临时存活、局部有效**

```python
z = 30  # 全局

def func1():
    x = 10
    print('func1:', id(z))  # 能访问全局的z

def func2():
    y = 20
    print('func2:', id(z))  # 也能访问z
    # print(x)  # NameError:访问不到func1的x

func1()
func2()
print('全局:', id(z))
# 三处打印的 id 相同,访问的是同一个 z
```

两个**没有嵌套关系**的函数，各自的局部名字彼此独立；但全局和内置的名字都能访问。

:::tip[技巧]
`if`、`for`、`while` 的代码块**不产生新的名称空间**，其中定义的名字在顶级代码里就是**全局名字**。
:::

## 7.11 global 修改全局变量

```python
x = 10

def func():
    x = 20  # 产生新的局部x,不影响全局

func()
print(x)  # 输出: 10
```

在函数内修改全局 `x` 的值，要用 `global` 声明：

```python
x = 10

def func():
    global x  # 声明 x 是全局的 x
    x = 20

func()
print(x)  # 输出: 20
```

**适用场景**：在局部修改全局名字对应的**不可变类型**。
**可变类型**的情况：修改内容不需要 `global`，重新赋值才需要。
```python
l = [1, 2, 3]

def func1():
    l = [4, 5]  # 重新赋值产生新列表,是局部的(要改全局需 global)

def func2():
    l.append(4)  # 只修改内容:局部没有 l,去全局找到并修改

func1()
func2()
print(l)  # 输出: [1, 2, 3, 4]
```


:::warning[注意]
实际开发中应尽量少用 `global`。多个函数随意修改全局变量，会让程序难以排查问题；更好的做法是通过**参数传入**、**`return` 返回**。
:::

## 7.12 nonlocal 修改外层函数变量

`nonlocal` 用于修改**外层函数**（E）的名字，而不是全局（G）。
```python
x = 10

def func1():
    x = 20
    def func2():
        nonlocal x  # 声明 x 是外层 func1 的 x
        x = 30
    print('调用func2之前:', x)
    func2()
    print('调用func2之后:', x)

func1()
print('全局:', x)
# 输出:
# 调用func2之前: 20
# 调用func2之后: 30
# 全局: 10
```

**查找范围**：`nonlocal` 只在外层函数（E）中查找，**所有 E 都没有就直接报错，不会去全局找**。
```python
x = 10

def func1():
    # x = 20  注释掉
    def func2():
        nonlocal x  # 外层 func1 里没有 x，直接报错
        x = 30

# 会报错: SyntaxError: no binding for nonlocal 'x' found
```

即使不调用函数，运行也会报 `SyntaxError`，**因为定义阶段就要确定查找顺序**。
### 7.12.1 修改名字的方式总结

| 要修改的名字在 | 需要做什么 |
|---|---|
| L（本地） | 直接改 |
| E（外层函数） | `nonlocal` 声明 |
| G（全局） | `global` 声明 |


:::tip[技巧]
可变类型只**修改内容**（如 `list.append`）时都不需要声明；只有**重新赋值绑定**才需要 `global` / `nonlocal`。
:::

## 7.13 闭包函数

### 7.13.1 什么是闭包

- **闭**：函数定义在另一个函数内部，被封闭起来
- **包**：内层函数引用了**外层函数**作用域中的名字（**不包括全局**）

```python
def f1():
    x = 10        # 外层函数 f1 局部的名字
    def f2():     # 闭:f2 定义在 f1 内部
        print(x)  # 包:f2 引用了外层 f1 的 x
```

### 7.13.2 把闭包函数拿到全局

`f2` 被封闭在 `f1` 内，全局访问不到，通过 `return` 把它返回：

```python
def f1():
    x = 10
    def f2():
        print(x)
    return f2  # 返回 f2 的内存地址(不加括号)

res = f1()  # res 就是 f2 的内存地址
print(res)  # 输出: <function f1.<locals>.f2 at 0x...>
res()       # 输出: 10
```

这打破了作用域限制，把局部函数拿到全局调用。无论在哪调用，`f2` 用的都是“包”里的 `x`：

```python
def f1():
    x = 10
    def f2():
        print(x)
    return f2

res = f1()
x = 20   # 全局的 x
res()    # 输出: 10  而不是 20
```

### 7.13.3 闭包是给函数传值的第二种方式

把 `x` 定义成 `f1` 的参数：

```python
def f1(x):    # x 作为外层函数的参数
    def f2():
        print(x)
    return f2

res = f1(10)
res()   # 输出: 10

res2 = f1(99)
res2()  # 输出: 99
```

传给 `f1` 什么，`f2` 用的就是什么。所以闭包是**另一种给函数传值的方式**：

1. **直接通过参数**传
2. **通过闭包**把值“包”给函数

**使用场景**：原函数不能再增加形参，而函数内部又需要外部值时，用闭包。这正是**装饰器**的基础。

:::note[补充]
可以通过 `__closure__` 属性查看被“包”住的值：`f1(10).__closure__[0].cell_contents` 结果为 `10`；非闭包函数的 `__closure__` 为 `None`，可用它来判断一个函数是不是真正引用了外层局部名字。
:::

## 7.14 函数作为对象传递

函数名和变量名一样：**函数名指向函数的内存地址**。既然如此，函数名就可以像变量名一样被传递。
### 7.14.1 四种用法

**1. 赋值给其他变量**

```python
def func():
    print('我是func')

x = func  # 不加括号,把内存地址赋给 x
x()       # x 加括号调用  输出: 我是func
```

**2. 作为参数传递**

```python
def func():
    print('我是func')

def func3(x):
    x()  # x 就是 func 的地址,加括号调用

func3(func)  # 输出: 我是func
```

**3. 作为返回值**

```python
def func():
    print('我是func')

def func2(x):
    return x  # 返回传进来的函数

res = func2(func)
res()  # 输出: 我是func
```

**4. 作为容器元素**

```python
def func():
    print('我是func')

l = [func]
l[0]()  # 输出: 我是func

d = {'k': func}
d['k']()  # 输出: 我是func
```


:::note[补充]
能被赋值、传参、返回、放进容器的对象称为“第一类对象”（First-class Object）。内置函数也一样，如 `p = print` 后 `p('hi')` 等同于 `print('hi')`。
:::

## 7.15 闭包实战：计数器

利用闭包保存状态，实现每调用一次就加 1 的计数器：

```python
def make_counter():
    count = 0
    def add():
        nonlocal count  # 修改外层函数的 count
        count += 1
        print('count =', count)
    return add

counter = make_counter()
counter()  # 输出: count = 1
counter()  # 输出: count = 2
counter()  # 输出: count = 3
```

每次调用 `counter`，`count` 都保留上次的值。这正是闭包的威力：**外层函数的局部变量不会随调用结束而销毁**，而是被内层函数“包”住一直存活。
## 7.16 实战：电子钱包菜单

用“**函数 + 字典**”取代冗长的 `if...elif`，实现可扩展的菜单系统。
### 7.16.1 第一版：if...elif 判断

```python
def login():
    print('执行登录功能')

def scan():
    print('执行扫码支付功能')

def transfer():
    print('执行转账功能')

while True:
    print('''
    0 退出
    1 登录
    2 扫码支付
    3 转账
    ''')
    opt = input('请输入功能编号: ').strip()
    if opt == '0':
        break
    elif opt == '1':
        login()
    elif opt == '2':
        scan()
    elif opt == '3':
        transfer()
    else:
        print('此功能不存在')
```

问题：**新增功能需要加 `elif`**，功能一多代码就冗长。
### 7.16.2 第二版：字典映射

```python
func_dic = {
    '1': login,
    '2': scan,
    '3': transfer,
}

while True:
    print('...')  # 菜单省略
    opt = input('请输入功能编号: ').strip()
    if opt == '0':
        break
    if opt not in func_dic:
        print('此功能不存在')
        continue
    func_dic[opt]()  # 根据编号取出函数并调用
```

**优势**：新增功能只需写函数和加一条字典项，主循环逻辑完全不用动。
### 7.16.3 第三版：菜单自动生成

让字典的 value 存**元组**：索引 0 是函数，索引 1 是功能名称。退出不需要函数，用 `None` 占位。
```python
def login():
    print('执行登录功能')

def scan():
    print('执行扫码支付功能')

def transfer():
    print('执行转账功能')

def query():
    print('执行查询余额功能')

func_dic = {
    '0': (None, '退出'),
    '1': (login, '登录'),
    '2': (scan, '扫码支付'),
    '3': (transfer, '转账'),
    '4': (query, '查询余额'),
}

while True:
    for key in func_dic:
        print(key, func_dic[key][1])  # 索引1是功能名称
    opt = input('请输入功能编号: ').strip()
    if opt == '0':
        break
    if opt not in func_dic:
        print('此功能不存在')
        continue
    func_dic[opt][0]()  # 索引0是函数的内存地址
```

**优势**：

- **菜单根据字典自动生成**，不用手写菜单文本
- 新增功能只需写函数、改字典
- 字典 value 用**元组**：这些内容不会修改，元组是不可变类型，从专业角度更合理

## 7.17 实战：哥德巴赫猜想验证

**哥德巴赫猜想**：任意大于 2 的偶数都可以表示为两个质数之和。
先实现判断质数的函数：

```python
def is_prime(n):
    """判断n是否为质数"""
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

print(is_prime(7))   # 输出: True
print(is_prime(10))  # 输出: False
```

再验证偶数是否满足猜想：

```python
def verify_goldbach(n):
    """验证偶数n是否符合哥德巴赫猜想"""
    if n <= 2 or n % 2 != 0:
        print(f'{n}不是大于2的偶数')
        return

    for i in range(2, n):
        if is_prime(i) and is_prime(n - i):
            print(f'{n} = {i} + {n - i}')
            return
    print(f'{n}找不到两个质数之和')

verify_goldbach(8)    # 输出: 8 = 3 + 5
verify_goldbach(20)   # 输出: 20 = 3 + 17
verify_goldbach(100)  # 输出: 100 = 3 + 97
```

这里 `n ** 0.5` 是开平方，只需试除到 `√n` 就能判断质数，是对朴素写法的优化。
## 7.18 定义阶段确定“局部有这个名字”

```python
input = 10

def func1():
    def func2():
        print(input)
    func2()
    input = 20  # 定义在调用之后

func1()
# 报错: cannot access free variable 'input' where it is not associated with a value in enclosing scope
```

直觉上调用 `func2` 时 `input = 20` 还没执行，应该去全局找到 `10`；但实际报错了。
**原因**：名字的查找顺序在**定义阶段**就确定了。定义函数时虽不执行代码，但会检测语法，**已经确定“`func1` 的局部有一个 `input`”**，所以 `func2` 找 `input` 只会去 `func1` 的局部，不会再去全局。调用时才发现这个 `input` 还没赋值，于是报错。
这也是“**变量先定义、后引用**”的体现。
## 本章小结

- 函数解决代码冗余、可维护性差的问题，原则是**先定义，后调用**
- 定义阶段只检测语法、不执行代码（语法错误和 `nonlocal` 绑定失败除外），调用时通过函数名找到地址、加括号触发执行
- 形参相当于变量名，实参相当于变量值；调用时绑定，结束时解除
- 位置形参必须传值；位置实参按顺序对应；关键字实参可指名传值，且必须写在位置实参之后
- 默认形参可不传，默认值**在定义阶段赋值**，不要用可变类型（用 `None` 占位代替）
- `*args` 打包多余的位置实参为元组，`**kwargs` 打包多余的关键字实参为字典
- 形参中的 `*`、`**` 是打包，实参中的 `*`、`**` 是打散
- 参数顺序：位置形参 → 默认形参 → `*args` → `**kwargs`
- `return` 立刻结束函数，多个值自动打包成元组
- `*args, **kwargs` 原封不动转交参数，是装饰器的核心机制
- 名称空间是栈区中名字的分类：内置、全局、局部，三者独立互不冲突
- 内置在解释器启动时产生，全局在文件执行前产生，局部在函数调用时产生
- LEGB 查找规则：Local → Enclosing → Global → Built-in，从当前位置开始，**以定义阶段为准**
- 全局作用域（内置 + 全局）全局存活、全局有效；局部作用域临时存活、局部有效
- 改 L 直接改，改 E 用 `nonlocal`，改 G 用 `global`；可变类型只修改内容时都不需声明
- 闭包：内层函数定义在外层函数内部（闭），并引用**外层函数**的名字（包）
- 闭包是给函数传值的第二种方式，适用于函数不能增加形参的场景，是装饰器的基础
- 函数名指向函数的内存地址，可以被赋值、作为参数、作为返回值、放进容器
- 字典 + 函数可取代冗长的 `if...elif`，实现可扩展、菜单自动生成的程序
