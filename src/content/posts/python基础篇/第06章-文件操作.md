## 6.1 文件操作基础

### 6.1.1 什么是文件

**文件是操作系统提供的虚拟概念,用来操作硬盘。** 从用户角度看,文件就是硬盘上的一个个数据集合;从操作系统角度看,文件是对硬盘数据的抽象封装。
**文件分类**

- **文本文件**:由字符组成,人类可读,如 .txt、.py、.md
- **二进制文件**:由字节组成,人类不可读,如图片、视频、音频

### 6.1.2 open 函数

`open(文件路径, 模式, encoding=编码)` 打开文件,返回文件对象。
**模式分两大类**

1. **控制读写操作**:`r`(读)、`w`(写)、`a`(追加)、`+`(读写)、`x`(独占创建)
2. **控制读写内容**:`t`(文本)、`b`(二进制)

**必须组合两类模式**,默认 `rt`:

- `rt`、`wt`、`at`:文本模式
- `rb`、`wb`、`ab`:二进制模式
- `r+`、`w+`、`a+`:读写模式

```python
# 文本模式,必须指定 encoding
f = open('test.txt', 'r', encoding='utf-8')
# 二进制模式,不能指定 encoding
f = open('test.jpg', 'rb')
```

### 6.1.3 路径处理

**转义字符问题**

Windows 路径用反斜杠 `\`,但 `\` 是转义字符:

- `\n`:换行
- `\t`:制表符
- `\\`:反斜杠本身
- `\a`:响铃

**三种解决方案**

```python
# 1. 双反斜杠
f = open('D:\\test\\a.txt', 'r', encoding='utf-8')

# 2. 正斜杠(推荐)
f = open('D:/test/a.txt', 'r', encoding='utf-8')

# 3. 原始字符串
f = open(r'D:\test\a.txt', 'r', encoding='utf-8')
```

**绝对路径 vs 相对路径**

- 绝对路径:从根目录开始,如 `D:/project/test.txt`
- 相对路径:从当前工作目录开始,如 `./test.txt` 或 `../data/test.txt`

### 6.1.4 文件资源管理

**文件占用两种资源**

1. 应用程序资源(变量 `f`)
2. 操作系统资源(OS 打开的文件句柄)

**必须调用 `f.close()` 释放 OS 资源**(OS 同时打开的文件数量有限)。
**with 语句:自动关闭文件**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()
# 离开 with 代码块,文件自动关闭

# 同时打开多个文件
with open('source.txt', 'r', encoding='utf-8') as f1, \
     open('target.txt', 'w', encoding='utf-8') as f2:
    content = f1.read()
    f2.write(content)
```


:::tip[技巧]
**永远用 with 打开文件**,避免忘记 `close()` 导致资源泄漏。
:::

## 6.2 读模式(r)

### 6.2.1 基本用法

**文件不存在 → FileNotFoundError**

```python
with open('not_exist.txt', 'r', encoding='utf-8') as f:
    pass
# 报错: FileNotFoundError: [Errno 2] No such file or directory
```

**文件存在 → 指针在开头**

```python
# 假设 test.txt 内容为: hello\nworld
with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)
# 输出:
# hello
# world
```

### 6.2.2 read 方法

**read() 无参数:一次读完**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()      # 从指针位置读到文件末尾
    print(content)
    content2 = f.read()     # 指针已在末尾,返回空字符串
    print(repr(content2))   # 输出: ''
```

**read(n):读 n 个字符**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    chunk1 = f.read(2)      # 读 2 个字符
    chunk2 = f.read(3)      # 再读 3 个字符
    print(chunk1, chunk2)
```


:::warning[注意]
t 模式的 `read(n)` 中 n 是字符数,b 模式中 n 是字节数。
:::

### 6.2.3 文件指针

**文件指针追踪当前读写位置**(以字节为单位,即使在 t 模式也是)。
```python
with open('test.txt', 'r', encoding='utf-8') as f:
    print(f.tell())         # 当前指针位置,输出: 0
    f.read(5)
    print(f.tell())         # 读了 5 个字符后的指针位置
```

### 6.2.4 其他读取方法

**readline():读一行**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    line1 = f.readline()    # 读第一行(包含 \n)
    line2 = f.readline()    # 读第二行
    print(repr(line1), repr(line2))
```

**readlines():读所有行到列表**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()   # 返回列表,每个元素是一行
    print(lines)            # ['hello\n', 'world\n']
```


:::warning[注意]
`readlines()` 把整个文件读入内存,大文件会占用大量内存,不推荐使用。
:::

**for 循环:逐行迭代(推荐)**

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    for line in f:          # 自动逐行读取,内存友好
        print(line.strip())  # strip() 去除末尾的 \n
```

## 6.3 写模式(w)

### 6.3.1 基本特性

**文件不存在 → 创建新文件**

```python
with open('new.txt', 'w', encoding='utf-8') as f:
    f.write('hello')
# new.txt 被创建,内容为 hello
```

**文件存在 → 立即清空**

```python
# test.txt 原内容: old content
with open('test.txt', 'w', encoding='utf-8') as f:
    pass
# 打开时 test.txt 内容就被清空了,即使没有写入
```


:::warning[注意]
w 模式打开文件的瞬间就会清空原内容,非常危险,使用前务必确认。
:::

### 6.3.2 write 方法

**write(字符串):写入内容**

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('hello')        # 不会自动添加换行符
    f.write('world')
# 文件内容: helloworld

with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('hello\n')      # 手动添加 \n
    f.write('world\n')
# 文件内容:
# hello
# world
```

**同一次打开中多次 write 会追加**

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('line1\n')
    f.write('line2\n')      # 追加,不会清空
# 文件内容:
# line1
# line2
```

**多次打开每次都清空**

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('first')

with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('second')
# 最终文件只有: second
```

### 6.3.3 writelines 方法

**writelines(列表):批量写入**

```python
lines = ['apple\n', 'banana\n', 'cherry\n']
with open('test.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)     # 不会自动添加 \n,需要自己在元素中包含
# 文件内容:
# apple
# banana
# cherry
```

### 6.3.4 w 模式不能读

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('hello')
    content = f.read()      # 报错: io.UnsupportedOperation: not readable
```

## 6.4 追加模式(a)

### 6.4.1 基本特性

**文件不存在 → 创建新文件**

**文件存在 → 指针跳到末尾,不清空**

```python
# test.txt 原内容: old content
with open('test.txt', 'a', encoding='utf-8') as f:
    f.write('\nnew line')
# 文件内容:
# old content
# new line
```

### 6.4.2 应用场景

**日志文件**

```python
import time

with open('app.log', 'a', encoding='utf-8') as f:
    log = f'{time.strftime("%Y-%m-%d %H:%M:%S")} - 用户登录\n'
    f.write(log)
# 每次运行追加一条日志,不会覆盖之前的记录
```

**用户注册**

```python
def register(username, password):
    with open('users.txt', 'a', encoding='utf-8') as f:
        f.write(f'{username}----{password}\n')

register('zhangsan', '123456')
register('lisi', 'abc123')
# users.txt 内容:
# zhangsan----123456
# lisi----abc123
```

### 6.4.3 a 模式不能读

```python
with open('test.txt', 'a', encoding='utf-8') as f:
    content = f.read()      # 报错: io.UnsupportedOperation: not readable
```

## 6.5 读写模式(+ 系列)

### 6.5.1 r+ 模式

- 基于 r,文件必须存在
- 指针在开头
- **写入会覆盖**(从当前指针位置开始覆盖)

```python
# test.txt 原内容: hello world
with open('test.txt', 'r+', encoding='utf-8') as f:
    content = f.read()      # 读完后指针在末尾
    f.write('\nnew')        # 在末尾追加
# 文件内容:
# hello world
# new

# test.txt 原内容: hello world
with open('test.txt', 'r+', encoding='utf-8') as f:
    f.write('HI')           # 从开头覆盖 2 个字符
# 文件内容: HIllo world
```

### 6.5.2 w+ 模式

- 基于 w,打开时清空
- 可以读,但指针在写入后的位置

```python
with open('test.txt', 'w+', encoding='utf-8') as f:
    f.write('hello')
    f.seek(0)               # 移动指针到开头
    content = f.read()
    print(content)          # 输出: hello
```

### 6.5.3 a+ 模式

- 基于 a,指针在末尾
- 可以读,但读不到内容(指针已在末尾)

```python
with open('test.txt', 'a+', encoding='utf-8') as f:
    content = f.read()      # 指针在末尾,读到的是空字符串
    f.seek(0)               # 移动到开头
    content = f.read()      # 现在能读到内容了
    print(content)
```


:::note[补充]
`+` 系列模式实际使用较少,需要读写结合时通常分两次打开(一次 r,一次 w)更清晰。
:::

## 6.6 二进制模式(b)

### 6.6.1 为什么需要 b 模式

**t 模式不能读取图片等二进制文件**

```python
with open('image.jpg', 'r', encoding='utf-8') as f:
    content = f.read()
# 报错: UnicodeDecodeError: 'utf-8' codec can't decode...
```

**b 模式是搬运工**:按原样读写字节,不编码不解码。
### 6.6.2 b 模式基本用法

```python
# 读取图片
with open('image.jpg', 'rb') as f:
    data = f.read()
    print(type(data))       # 输出: <class 'bytes'>

# 写入图片
with open('copy.jpg', 'wb') as f:
    f.write(data)
```

**b 模式特点**

1. 不能指定 `encoding` 参数
2. 读取返回 `bytes` 类型
3. 写入必须传入 `bytes` 类型

```python
with open('test.txt', 'rb') as f:
    data = f.read()
    print(data)             # 输出: b'hello\nworld'

with open('test.txt', 'wb') as f:
    f.write(b'hello')       # 必须写 bytes
    # f.write('hello')      # 报错: a bytes-like object is required
```

### 6.6.3 bytes 类型创建

```python
# 方式 1: b'' 前缀(只能包含 ASCII)
b1 = b'abc123'
print(b1)                   # 输出: b'abc123'

# 方式 2: encode
b2 = '你好'.encode('utf-8')
print(b2)                   # 输出: b'\xe4\xbd\xa0\xe5\xa5\xbd'

# 方式 3: bytes 构造函数
b3 = bytes('你好', encoding='utf-8')
print(b3)                   # 输出: b'\xe4\xbd\xa0\xe5\xa5\xbd'
```

### 6.6.4 b 模式读取方法

**read(n):读 n 个字节**

```python
with open('test.txt', 'rb') as f:
    chunk = f.read(3)       # 读 3 个字节
    print(chunk)            # b'hel'
```

**for line in f:仍然按行读**(遇到 `\n` 字节分割)

```python
with open('test.txt', 'rb') as f:
    for line in f:
        print(line)
# 输出:
# b'hello\n'
# b'world\n'
```

**分块读取:内存安全的最佳实践**

```python
with open('large_file.dat', 'rb') as f:
    while True:
        chunk = f.read(1024)    # 每次读 1KB
        if not chunk:
            break
        # 处理 chunk
```


:::tip[技巧]
对于大文件,分块读取是最安全的方式,既不会一次性占用太多内存,也不会像按行读取那样遇到没有换行符的文件时失效。
:::

### 6.6.5 通用拷贝工具

**结合 b 模式和分块读取,可以拷贝任意文件**

```python
def copy_file(src, dst):
    """通用文件拷贝函数"""
    with open(src, 'rb') as f_src, open(dst, 'wb') as f_dst:
        while True:
            chunk = f_src.read(1024)
            if not chunk:
                break
            f_dst.write(chunk)

# 拷贝文本文件
copy_file('test.txt', 'test_copy.txt')
# 拷贝图片
copy_file('image.jpg', 'image_copy.jpg')
# 拷贝视频
copy_file('video.mp4', 'video_copy.mp4')
```

## 6.7 文件指针控制

### 6.7.1 seek 方法

**seek(offset, whence):移动指针**

| whence | 含义 | offset 要求 | t 模式是否可用 |
|---|---|---|---|
| 0 | 相对开头 | 正数 | 可用 |
| 1 | 相对当前 | 正负皆可 | 不可用 |
| 2 | 相对末尾 | 负数 | 不可用 |

```python
with open('test.txt', 'rb') as f:
    # 模式 0:相对开头
    f.seek(5, 0)            # 移动到第 5 字节
    print(f.tell())         # 输出: 5

    # 模式 1:相对当前
    f.seek(3, 1)            # 从当前位置向后移 3 字节
    print(f.tell())         # 输出: 8

    # 模式 2:相对末尾
    f.seek(-2, 2)           # 从末尾向前移 2 字节
    print(f.tell())
```


:::warning[注意]
t 模式只能用 `seek(n, 0)` 或 `seek(0, 2)`,模式 1 和 2 只能在 b 模式使用。
:::

### 6.7.2 tell 方法

**tell():返回当前指针位置(字节偏移量)**

```python
with open('test.txt', 'rb') as f:
    print(f.tell())         # 输出: 0
    f.read(10)
    print(f.tell())         # 输出: 10
```

### 6.7.3 实战:监控日志文件(tail -f)

**需求**:实时监控日志文件,新增内容自动打印(类似 Linux 的 `tail -f`)。
**writer.py:模拟写日志**

```python
import time

with open('app.log', 'ab') as f:
    for i in range(10):
        time.sleep(1)
        f.write(f'Log entry {i}\n'.encode('utf-8'))
        f.flush()           # 强制刷新到硬盘
```

**reader.py:实时监控**

```python
import time

with open('app.log', 'rb') as f:
    f.seek(0, 2)            # 指针跳到末尾
    while True:
        line = f.readline()
        if line:
            print(line.decode('utf-8'), end='')
        else:
            time.sleep(0.2) # 没有新内容,休眠后继续尝试
```

**运行**:

1. 先运行 `python reader.py`
2. 再运行 `python writer.py`
3. reader 会实时打印 writer 写入的内容


:::note[补充]
必须用 b 模式,因为需要 `seek(0, 2)`;writer 要用 `flush()` 强制刷新,否则内容可能还在缓冲区。
:::

## 6.8 文件修改

### 6.8.1 硬盘的限制

**硬盘没有"插入数据"操作,只能用新数据覆盖旧数据。**

如果要在文件中间插入一段文字,硬盘需要:

1. 把插入点后的所有数据向后移动
2. 每个字节都要重新写入

这会导致大量 IO 操作,严重缩短硬盘寿命,所以操作系统不提供这种功能。
**文本编辑器如何修改文件**

1. 把整个文件读入内存
2. 在内存中修改
3. 用 w 模式覆盖整个文件

这就是为什么大文件编辑器会卡顿,以及为什么"自动保存"会拖慢性能。
### 6.8.2 方法一:全部读入内存修改

**思路**:把文件完整读入内存,修改后一次性覆盖写回。
```python
# 示例:把 test.txt 中所有的 "old" 替换成 "new"

# 方式 1:str.replace()
with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    new_content = content.replace('old', 'new')

with open('test.txt', 'w', encoding='utf-8') as f:
    f.write(new_content)

# 方式 2:readlines() + 列表操作
with open('test.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
    lines.insert(2, 'inserted line\n')   # 在第 3 行前插入

with open('test.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)
```

**优点**:用户体验好,文本编辑器都用这种方式。
**缺点**:整个文件占内存,大文件性能差。
### 6.8.3 方法二:逐行写入新文件

**思路**:边读边写,只有一行在内存,最后替换原文件。
```python
import os

# 读原文件,修改后写入临时文件
with open('test.txt', 'r', encoding='utf-8') as f, \
     open('.test.txt.swap', 'w', encoding='utf-8') as new_f:
    for line in f:
        new_line = line.replace('old', 'new')
        new_f.write(new_line)

# 删除原文件
os.remove('test.txt')
# 重命名临时文件
os.rename('.test.txt.swap', 'test.txt')
```

**优点**:内存友好,同一时刻只有一行在内存,适合大文件。
**缺点**:

- 临时占用双倍磁盘空间
- 修改过程中断电会丢失数据(临时文件可以部分恢复)


:::tip[技巧]
Linux 惯例:临时文件以 `.` 开头(隐藏文件),以 `.swap` 结尾。
:::

### 6.8.4 更安全的方法:os.replace()

**问题**:`os.remove()` + `os.rename()` 不是原子操作,中间出错会导致两个文件都没了。
**解决**:`os.replace()` 是原子操作,一步完成删除和重命名。
```python
import os

with open('test.txt', 'r', encoding='utf-8') as f, \
     open('.test.txt.swap', 'w', encoding='utf-8') as new_f:
    for line in f:
        new_line = line.replace('old', 'new')
        new_f.write(new_line)

os.replace('.test.txt.swap', 'test.txt')   # 原子操作,更安全
```

### 6.8.5 方法对比

| | 方式一:全部读入内存 | 方式二:逐行写入新文件 |
|---|---|---|
| 内存占用 | 整个文件,大文件性能差 | 只有一行,内存友好 |
| 磁盘占用 | 原文件大小 | 双倍(临时文件) |
| 使用场景 | 文本编辑器(用户体验优先) | 应用程序(性能优先) |

## 6.9 其他文件方法

### 6.9.1 flush:强制刷新

**问题**:写入文件时,数据可能暂存在缓冲区,没有立即写入硬盘。
**解决**:`f.flush()` 强制将缓冲区内容写入硬盘。
```python
import time

with open('test.txt', 'w', encoding='utf-8') as f:
    for i in range(10):
        f.write(f'line {i}\n')
        f.flush()           # 立即写入硬盘,不等缓冲区满
        time.sleep(1)
```

**何时用 flush**:

- 日志记录:确保程序崩溃前日志已保存
- 进度监控:让其他程序实时读取进度
- 通常不需要:OS 会自动优化刷新时机,`close()` 时也会自动刷新

### 6.9.2 文件对象属性


### 6.10.4 完整的登录注册系统

```python
def login():
    """用户登录"""
    inp_user = input('用户名:').strip()
    inp_pwd = input('密码:').strip()

    with open('users.txt', 'r', encoding='utf-8') as f:
        for line in f:
            username, password = line.strip().split('----')
            if inp_user == username and inp_pwd == password:
                print('登录成功')
                return True
    print('账号或密码错误')
    return False

def register():
    """用户注册"""
    username = input('用户名:').strip()
    password = input('密码:').strip()

    # 检查用户名是否已存在
    try:
        with open('users.txt', 'r', encoding='utf-8') as f:
            for line in f:
                user, _ = line.strip().split('----')
                if user == username:
                    print('用户名已存在')
                    return
    except FileNotFoundError:
        pass  # 文件不存在,说明是第一个用户

    # 追加新用户
    with open('users.txt', 'a', encoding='utf-8') as f:
        f.write(f'{username}----{password}\n')
    print('注册成功')

def main():
    """主程序"""
    while True:
        choice = input('1.登录 2.注册 3.退出\n请选择:').strip()
        if choice == '1':
            if login():
                print('欢迎使用系统')
                break
        elif choice == '2':
            register()
        elif choice == '3':
            print('再见')
            break
        else:
            print('无效选择')

if __name__ == '__main__':
    main()
```

## 本章小结

- **文件是 OS 提供的虚拟概念**,用来操作硬盘;分文本文件和二进制文件。
- **open 函数**:两类模式必须组合,控制读写(`r/w/a`)和内容类型(`t/b`);默认 `rt`。
- **路径处理**:用正斜杠或原始字符串避免转义字符;绝对路径从根目录,相对路径从当前目录。
- **资源管理**:文件占用应用和 OS 两种资源,必须 `close()`;**永远用 with 自动管理**。
- **r 模式**:文件不存在报错,指针在开头;`read()` 一次读完,`read(n)` 读 n 个字符;`for line in f` 逐行读取(推荐)。
- **w 模式**:文件不存在则创建,存在则立即清空;`write()` 不自动换行;同一次打开多次 write 追加,多次打开每次清空。
- **a 模式**:文件不存在则创建,存在则指针跳到末尾;适合日志、注册等场景。
- **+ 系列**:`r+` 基于 r 可读写但覆盖,`w+` 基于 w 但可读,`a+` 基于 a 但可读;实际使用较少。
- **b 模式**:不编码不解码,按字节原样搬运;不能指定 encoding;读返回 bytes,写必须传 bytes;`read(n)` 的 n 是字节数。
- **通用拷贝**:b 模式 + `while True` + `read(1024)` 分块读取,可拷贝任意文件。
- **指针控制**:`seek(offset, whence)` 移动(模式 1、2 只能在 b 模式),`tell()` 查询位置;实战:tail -f 监控日志。
- **文件修改**:硬盘无插入操作,只能覆盖;方式一全读入内存(用户体验好),方式二逐行写新文件(内存友好);`os.replace()` 原子操作更安全。
- **其他方法**:`flush()` 强制刷新,`name`/`mode`/`encoding`/`readable()`/`writable()`/`closed` 属性。

```python
def encrypt_file(src, dst):
    """加密:每个字节 +10"""
    with open(src, 'rb') as f_src, open(dst, 'wb') as f_dst:
        while True:
            chunk = f_src.read(1024)
            if not chunk:
                break
            encrypted = bytes((b + 10) % 256 for b in chunk)
            f_dst.write(encrypted)

def decrypt_file(src, dst):
    """解密:每个字节 -10"""
    with open(src, 'rb') as f_src, open(dst, 'wb') as f_dst:
        while True:
            chunk = f_src.read(1024)
            if not chunk:
                break
            decrypted = bytes((b - 10) % 256 for b in chunk)
            f_dst.write(decrypted)
```
