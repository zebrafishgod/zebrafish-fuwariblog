## 2.1 变量的本质

### 2.1.1 什么是变量

**变量（variable）就是可以变化的量**，用来记录事物的状态。程序运行的本质就是一系列状态变化的过程。
类比《王者荣耀》：英雄等级从 1 升到 2、金币增加、英雄从"活着"变成"死了"——站在程序员角度，这些都是**变量的值在发生变化**。
### 2.1.2 先定义，后引用

变量使用原则：**先定义、后引用**。
```python
name = "梦泪"   # 定义变量
age = 73
print(name, age)  # 引用变量，输出: 梦泪 73
```

- **变量名**（`name`、`age`）：最好见名知意
- **赋值符号**（`=`）：将右侧值的内存地址绑定给左侧变量名
- **变量值**（`"梦泪"`、`73`）：记录事物的状态

未定义就引用会报错：

```python
# print(aa)  # 报错 NameError: name 'aa' is not defined
```

### 2.1.3 变量存储的是内存地址

程序运行中产生的数据优先存在**内存**里。定义变量时：

1. 在内存中开辟一块空间，把值存进去
2. **把这块空间的内存地址绑定给变量名**
3. 通过变量名可以找到内存地址，再访问到值

**重要概念纠正**：变量不是"存数据的容器"，**变量存储的是对象的内存地址（引用）**，而不是数据本身。
```python
a = 100
b = a     # b 得到的是 100 的内存地址，a 和 b 指向同一个对象
c = a
print(id(a) == id(b) == id(c))  # 输出: True
```

```text
a ──┐
b ──┼──▶ 100 的内存空间
c ──┘
```

### 2.1.4 变量的三大组成部分

| 组成 | 作用 |
|---|---|
| 变量名 | 指向值的内存地址，用来访问值 |
| 赋值符号 `=` | 将变量值的内存地址绑定给变量名 |
| 变量值 | 表示记录事物的状态 |

## 2.2 变量命名规则

### 2.2.1 命名原则

1. **见名知意**：用 `age` 而不是 `x`，用 `price` 而不是随意的字母
2. **只能由字母、数字、下划线组成**：习惯上**纯小写表示变量**，纯大写表示常量
3. **不能以数字开头**：`1age` 会报语法错误
4. **不能用 Python 关键字**：如 `if`、`for`、`class`、`True`；可用 `import keyword; print(keyword.kwlist)` 查看全部关键字
5. **最好不要覆盖内置名字**：如 `print`、`len`、`id`——覆盖后内置功能将不可用
6. **不用拼音和中文**：`年龄 = 73` 虽能运行但不规范
7. **多个单词用下划线连接**：`age_of_cat = 3`（蛇形命名 snake_case）

```python
age = 84
price = 84
age_of_cat = 3
print(age, price, age_of_cat)   # 输出: 84 84 3

# 以下写法不合法
# 1age = 18         # 以数字开头
# user-name = "a"   # 含有减号

# 覆盖内置名字的后果
# print = 10
# print("hi")       # 报错 TypeError: 'int' object is not callable
```


:::tip[技巧]
PyCharm 格式化代码：`Ctrl + Alt + L`，自动整理等号两边空格、注释空格等格式。
:::

## 2.3 常量约定

**常量（constant）就是不变的量**，如圆周率、程序中不希望被修改的配置值。
**Python 语法中没有常量概念**，所有量都是变量。约定：**把变量名全部写成大写字母，表示这是常量**，程序员看到后就知道不应该修改。
```python
PI = 3.141592653589   # 全大写：约定为常量
AGE = 18

radius = 2
print(PI * radius * radius)   # 输出: 12.566370614356

AGE = 19              # 语法上可以修改，不会报错，但违反了约定
print(AGE)            # 输出: 19
```

Python 的特点：很多方面不在语法上限制你，只从规范层面约束你，让语言更简洁。

:::note[补充]
Python 3.8 起可用 `typing.Final` 标注常量，如 `from typing import Final` 后写 `MAX_SIZE: Final = 100`，运行时依然不阻止修改，但 PyCharm、mypy 等工具会给出警告。
:::

## 2.4 变量的 id 与 type

### 2.4.1 id：对象的身份标识

**`id()`** 返回根据变量值的内存地址计算出来的一个整数标识。
**重要概念纠正**：`id()` 不是内存地址本身，而是由内存地址计算出来的整数映射，类似于"身份证号码"。
```python
name = "梦泪"
age = 73
price = 3.5

print(id(name))      # 输出示例: 2357213470192
print(id(age))       # 输出示例: 140732038891400
```


:::note[补充]
在 CPython 解释器中，`id()` 返回值实际上就等于对象的内存地址（十进制），可用 `hex(id(x))` 查看十六进制形式。这是实现细节，概念上按"内存地址的整数映射"理解即可。
:::

### 2.4.2 type：数据类型

事物的状态多种多样，变量值也应分为多种**类型**，用来记录不同的状态：

| 要记录的状态 | 合适的类型 | 示例 |
|---|---|---|
| 名字（文本） | 字符串 str，需要加引号 | `name = "梦泪"` |
| 年龄 | 整数 int | `age = 73` |
| 商品价格 | 小数 float | `price = 3.5` |

```python
print(type(name))    # 输出: <class 'str'>
print(type(age))     # 输出: <class 'int'>
print(type(price))   # 输出: <class 'float'>
```

## 2.5 is 与 == 的区别

- **`is`**：身份运算，比较两个值的 **id 是否相同**
- **`==`**：比较两个值**是否相等**

```python
a = "梦泪"
b = "梦泪"     # 两次赋值操作可能申请不同的内存空间

print(a == b)    # 输出: True —— 值相等
print(a is b)    # 在交互式环境输出: False —— id 不同（PyCharm 中可能优化为 True）
```

**结论**：

- **id 不同时，值可能相同**：不同内存空间可以存相同的值
- **id 相同时，值一定相同**：`a is b` 为 True 时，`a == b` 一定为 True
- **判断值是否相等用 `==`，判断是否为同一对象用 `is`**


:::tip[技巧]
判断一个值是否为 `None`，规范写法是 `if x is None:`，因为 `None` 在整个程序中只有一个对象。
:::

## 2.6 小整数池与编译器优化

### 2.6.1 小整数池

为避免重复创建常用整数带来的效率问题，Python 解释器启动时就预先创建 **-5 ~ 256** 的小整数，这些整数**永远不会被垃圾回收**。
```python
a = 10
b = 10
print(a is b)    # 输出: True —— 小整数池中的同一个对象

c = 5 + 5        # 运算结果 10 也直接用现成的
print(c is a)    # 输出: True

a = 257
b = 257
print(a is b)    # 交互式环境输出: False —— 超出范围，各自创建
```

### 2.6.2 编译器优化与运行环境差异

**运行 .py 文件**：解释器先将整份代码编译成字节码，能提前看到全部内容，遇到两个完全相同的常量会复用同一个对象（**编译器优化**）。
**交互模式**：逐行输入、逐行执行，每一行是分开的，无法提前看到全部内容，所以不会复用。
```python
# 保存为 .py 文件运行
a = 257
b = 257
print(a is b)   # 文件中运行通常输出: True（交互式逐行输入则为 False）
```


:::warning[注意]
小整数池、字符串驻留（string interning）、常量复用都是解释器的内部优化，结果可能随版本和运行方式变化。**写程序判断值是否相等一律用 `==`，不要依赖 `is`。**
:::


## 2.7 基本数据类型快速入门

### 2.7.1 数字类型：int 与 float

```python
age = 73         # int 整型
price = 3.5      # float 浮点型

# 数学运算
level = 1
level = level + 1
print(level)     # 输出: 2

print(10 - 3)    # 输出: 7
print(10 * 3)    # 输出: 30
print(10 / 4)    # 输出: 2.5

# int 与 float 可以跨类型相加，结果为 float
a = 3
b = 1.5
c = a + b
print(c, type(c))   # 输出: 4.5 <class 'float'>

# 比较运算
age = 20
print(age > 18)  # 输出: True
```


:::note[补充]
`//` 是整除、`%` 是取余、`**` 是乘方（如 `2 ** 10` 为 1024）。浮点数有精度误差，
如 `0.1 + 0.2` 结果为 `0.30000000000000004`。Python 的 int 没有大小上限。
:::

### 2.7.2 字符串类型：str

**字符串（str）** 就是一串字符（文本、字母、符号），用来记录描述性状态。
**定义方式**：用引号把字符引起来，可以是单引号、双引号或三引号。
```python
name = '梦泪'
content = """他出了一个名刀司命！"""

print(type(name))      # 输出: <class 'str'>

# 只要是引号引起来的，就算全是数字，也是字符串
a = 73
b = "73"
print(type(a))   # 输出: <class 'int'>
print(type(b))   # 输出: <class 'str'>
```

**引号的嵌套与转义**：

```python
a = 'My name is "梦泪"'      # 外单内双
b = "My name is '梦泪'"      # 外双内单
c = 'My name is \'梦泪\''    # 反斜杠转义
print(a)   # 输出: My name is "梦泪"
```

**字符串相加与相乘**：

```python
a = "my name is "
b = "梦泪"
print(a + b)          # 输出: my name is 梦泪

# print("年龄" + 18)  # 报错 TypeError：字符串不能和数字相加

print("梦泪" * 5)   # 输出: 梦泪梦泪梦泪梦泪梦泪

# 实用技巧：用横杠包裹内容
print("-" * 50)
print("我爱偷水晶")
print("-" * 50)
```

- 字符串只能与字符串相加（但效率极低，不推荐）
- 字符串可以与数字相乘，表示重复


:::note[补充]
大量拼接推荐用 `"".join(...)`，格式化输出推荐用 f-string。要把数字拼进字符串，可先用 `str(18)` 转换。
:::

### 2.7.3 列表类型：list

**列表（list）** 用来存多个值，可以按索引取指定位置的值。
**定义列表**：在中括号 `[]` 内用逗号分隔多个任意类型的值。
```python
l = [10, 3.5, "梦泪", ["a", "b"]]
print(type(l))   # 输出: <class 'list'>
```

**按索引取值**：第一个值对应 0 号索引，第二个对应 1 号，依此类推。
```text
l      = [ 10,  3.5,  "梦泪",  ["a", "b"] ]
正向索引:   0    1       2          3
反向索引:  -4   -3      -2         -1
```

```python
l = [10, 3.5, "梦泪", ["a", "b"]]
print(l[2])      # 输出: 梦泪
print(l[-1])     # 反向索引：最后一个元素，输出: ['a', 'b']
print(l[3][1])   # 嵌套取值，输出: b
```

**实际应用**：

```python
hobbies = ["可乐", "厕所", "烫头"]
print(hobbies[1])   # 输出: 厕所

# 存多个人的信息
person = [
    ["梦泪", 73, 100, ["可乐", "厕所", "烫头"]],
    ["韩信", 84, 200, ["打仗"]],
    ["李白", 95, 0.5, ["喝酒", "写诗", "练剑"]],
]

print(person[1][2])     # 韩信的工资，输出: 200
print(person[2][3][1])  # 李白的第二个爱好，输出: 写诗
```


:::warning[注意]
索引超出范围会报错 `IndexError: list index out of range`。也可以通过索引修改元素，如 `hobbies[1] = "游泳"`。
:::

### 2.7.4 字典类型：dict

**列表的缺陷**：索引只代表位置，对值没有任何描述性。
**字典（dict）** 既能存多个值，又能对这些值进行描述。

- 列表是**索引对应值**，字典是 **key 对应值**（键值对）
- key 通常为字符串类型，有描述性功能

```python
dic = {
    "name": "梦泪",
    "age": 73,
    "height": 150,
    "salary": 180,
}
print(type(dic))    # 输出: <class 'dict'>
```

**按 key 取值**：

```python
print(dic["name"])     # 输出: 梦泪
print(dic["salary"])   # 输出: 180
```

**列表与字典的混合嵌套**：

```python
person = [
    {"name": "梦泪", "age": 73, "hobbies": ["可乐", "厕所", "烫头"]},
    {"name": "韩信", "age": 84, "hobbies": ["打仗"]},
    {"name": "李白", "age": 95, "hobbies": ["喝酒", "写诗", "练剑"]},
]

# 列表用索引取，字典用 key 取
print(person[0]["hobbies"][2])   # 输出: 烫头
print(person[1]["hobbies"][0])   # 输出: 打仗
```


:::note[补充]
key 不存在时直接取值会报 `KeyError`；`dic["age"] = 74` 可以修改值，key 不存在时则会新增。key 必须是不可变类型。Python 3.7 起字典保持插入顺序。
:::

### 2.7.5 布尔值类型：bool

**布尔类型（bool）** 用来记录真和假两种状态。只有两个值：`True`（真）和 `False`（假）。
```python
is_alive = True
print(type(is_alive))   # 输出: <class 'bool'>

age = 20
print(age > 18)   # 输出: True
```

**值的真假**：

- **有值**的变量（数字、字符串、列表、字典）判断时为 **True**
- **数字 0、None、空字符串、空列表、空字典**判断时为 **False**

```python
print(bool(73), bool("梦泪"), bool([1]), bool({"a": 1}))
# 输出: True True True True

print(bool(0), bool(None), bool(""), bool([]), bool({}))
# 输出: False False False False False
```


:::note[补充]
`True`、`False` 首字母必须大写。`bool` 是 `int` 的子类，`True` 相当于 1、`False` 相当于 0，所以 `True + True` 的结果是 2。`None` 表示空值，类型为 `NoneType`，`None` 是该类型的唯一值。
:::

## 2.8 内存管理与引用计数

### 2.8.1 为什么需要内存管理

定义变量要占用内存，而**内存大小是有限的**。申请了内存空间用完后一定要释放，否则就是浪费内存资源。不释放内存最终会导致**内存溢出**。
Python 推出了**垃圾回收机制（Garbage Collection, GC）**，自动管理内存。
### 2.8.2 什么是垃圾

- 值绑定着变量名时，可以通过变量名引用到，**不是垃圾**
- 一旦没有绑定任何变量名，再也找不到这个值，它却还占着内存——这就是**垃圾**

垃圾回收机制用来**回收没有关联任何变量名的值**。
### 2.8.3 引用计数

**引用计数（reference counting）**：一个值身上绑定了几个变量名。
```python
a = 100   # 引用计数 1
b = a     # a、b 指向同一个地址，引用计数 2
c = a     # 引用计数 3
print(id(a) == id(b) == id(c))  # 输出: True
```

**引用计数增加**：

- 变量赋值：`b = a`
- 容器引用：列表、字典中存放对象的地址

**引用计数减少**：

```python
a = 100
b = a
c = a     # 引用计数 3

# 方式一：del 解除绑定关系
del a     # 引用计数变为 2
# print(a)  # 报错 NameError

# 方式二：重新赋值
c = 123   # c 改绑到 123，100 的引用计数变为 1
```

当引用计数为 0 时，Python 解释器自动回收这块内存空间。

:::note[补充]
可用 `sys.getrefcount(对象)` 观察引用计数，但返回值会把传参时的临时引用算进去，且小整数等被解释器共享的对象计数会很大。引用计数无法处理循环引用，Python 还配有标记清除和分代回收辅助机制。
:::

## 2.9 直接引用和间接引用

引用一个值的方式有两种：

- **直接引用**：直接通过变量名引用对应的值
- **间接引用**：通过容器（列表、字典等）中的元素引用到这个值

```python
name = "梦泪"          # "梦泪" 被 name 直接引用
l = ["a", "b", name]     # 索引 2 存的是 "梦泪" 的内存地址

print(l[2])              # 输出: 梦泪 —— 通过列表间接引用
print(id(name) == id(l[2]))  # 输出: True —— 同一个对象
```

此时"梦泪"的引用计数为 **2**（一次直接、一次间接）。
## 2.10 列表在内存中的存储方式

### 2.10.1 列表存的是地址

**列表不存放真正的值，只存放索引和值的内存地址。**

```text
 变量名           列表对象                      值
 ┌───┐        ┌─────────────────┐
 │ l │───────▶│ 0: "a" 的地址   │──────▶ "a"
 └───┘        │ 1: "b" 的地址   │──────▶ "b"
              │ 2: "c" 的地址   │──────▶ "c"
              └─────────────────┘
```

```python
a = 100
l = ["a", "b", "c"]
l.append(a)             # 新增索引 3，存放 100 的内存地址
print(l[3])             # 输出: 100
print(id(l[3]) == id(a))   # 输出: True
```

此时 100 的引用计数为 **1**（被 a 直接引用）+ **1**（被列表 l 间接引用）= **2**。
字典同理：**字典存的是 key 对应值的内存地址**。
### 2.10.2 变量改绑不影响列表

```python
name = "梦泪"
l = ["a", "b", name]    # 索引 2 存的是 "梦泪" 的内存地址
name = "李白"           # name 改绑到新对象，不影响列表

print(l[2])             # 输出: 梦泪
print(name)             # 输出: 李白
```

`name = "李白"` 只改变了变量名 name 的绑定关系，**根本没有改过列表 2 号索引的绑定关系**。

:::warning[注意]
反过来，如果多个地方引用的是同一个列表，通过任一处修改列表内部（如 `append`），所有引用它的地方都会看到变化——区分"改绑名字"和"修改容器内部"是理解可变与不可变类型的基础。
:::

## 2.11 循环引用与标记清除

### 2.11.1 循环引用导致内存泄漏

```python
l1 = ["a", "b"]
l2 = ["x", "y"]

l1.append(l2)    # l1 的索引 2 存 l2 的地址
l2.append(l1)    # l2 的索引 2 存 l1 的地址 —— 循环引用

del l1   # 解除变量名 l1 的绑定，但列表 1 被列表 2 间接引用，计数不为 0
del l2   # 解除变量名 l2 的绑定，但列表 2 被列表 1 间接引用，计数不为 0
```

两个列表的直接引用全部解除，我们再也访问不到它们，但引用计数不为 0，变成了**永远回收不了的垃圾**——这就是**内存泄漏（memory leak）**。
### 2.11.2 栈区与堆区

定义变量时有两部分要存：

- **栈区（stack）**：专门存放**变量名**
- **堆区（heap）**：专门存放**变量值**

执行 `name = "梦泪"` 时，堆区申请空间存入"梦泪"，栈区存放 `name` 并对应上这个内存地址。
### 2.11.3 标记清除机制

**标记清除（mark and sweep）** 解决循环引用问题。
当 Python 程序**内存空间不够用**时，标记清除会暂停程序，扫描栈区：

- 通过栈区能引用到的值（直接或间接），标记为**存活**状态
- 通过栈区引用不到的值，标记为**死亡**状态，直接清理

**就算引用计数不为 0，只要访问不到，标记清除就会把它当成垃圾回收。**

```python
import gc

l1 = ["a", "b"]
l2 = ["x", "y"]
l1.append(l2)
l2.append(l1)      # 形成循环引用

del l1
del l2             # 引用计数不为 0，引用计数机制回收不了

# 手动触发一次垃圾回收
print(gc.collect())   # 输出示例: 2 —— 两个列表被回收
```


:::note[补充]
CPython 实际实现中，只跟踪列表、字典、自定义对象等容器类对象（只有它们会形成循环引用），通过计算容器对象的外部引用数找出不可达的循环。
:::

## 2.12 分代回收机制

### 2.12.1 为什么需要分代回收

基于引用计数的垃圾回收，每次都需要遍历所有对象的引用计数，**效率非常低**。
**分代回收（generational collection）** 解决扫描效率问题：**多次扫描后依然存活的对象，被归入更高的代，扫描频率降低。**

### 2.12.2 类比：老师检查作业

- **第一天**：老师不了解情况，全部检查。40 人中 35 人按时完成，各盖一朵小红花
- **第二天**：仍全部检查，30 人完成，有了两朵小红花
- **第三天**：再全部检查，25 人完成，有了三朵小红花，被认为是**良好**同学，改为**一周检查一次**
- **从第四天开始**：老师每天只检查其余同学
- 良好同学连续三周完成，归入**优秀**分类，可能变成**一个月检查一次**

通过这样分类，整体扫描频率大幅降低，扫描效率大幅提高。
```python
import gc

# 查看三代的触发阈值
print(gc.get_threshold())   # 输出示例: (700, 10, 10)

# 查看当前各代中正在跟踪的对象数量
print(gc.get_count())       # 输出示例: (183, 4, 1)
```


:::note[补充]
CPython 中对象分 0、1、2 三代，新对象在第 0 代，每熬过一次回收就升一代，代数越高扫描越少。代价是：对象升到高代后才变成垃圾，要等较久才会被回收，即用"及时性"换"整体效率"。
:::

### 2.12.3 垃圾回收机制总结

- **引用计数**：主要机制，用来扫描并回收垃圾
- **标记清除**：解决引用计数回收不了的垃圾（循环引用）
- **分代回收**：解决引用计数扫描的效率问题

Python 垃圾回收 = **引用计数（主）+ 标记清除 + 分代回收（辅）**。
## 本章小结

- **变量本质**：存储的是对象的内存地址（引用），不是数据本身；`b = a` 是把地址给 b，而不是复制数据。
- **命名规则**：见名知意、字母数字下划线、不以数字开头、不覆盖内置名字、多词用下划线连接；全大写约定为常量。
- **id 与 type**：`id()` 是由内存地址计算出的整数标识，不是地址本身；`type()` 查看数据类型。
- **is 与 ==**：`is` 比 id，`==` 比值；判断相等用 `==`，判断是否为 `None` 用 `is`。
- **小整数池**：-5 ~ 256 启动时创建、永不回收；文件运行时编译器优化会复用相同常量，交互式逐行执行则不会。
- **基本数据类型**：int/float（数学运算）、str（描述性状态）、list（索引取值）、dict（key 取值）、bool（真假）。
- **引用计数**：值身上绑定的变量名个数；直接引用（变量名）和间接引用（容器）都会让计数加 1。
- **列表存储**：列表存的是"索引 → 值的内存地址"，字典存的是"key → 值的内存地址"；变量名改绑不影响列表中已存放的地址。
- **循环引用**：两个容器互相引用，del 掉所有变量名后引用计数仍不为 0，造成内存泄漏；标记清除从栈区扫描，访问不到的值一律清除。
- **分代回收**：多次扫描后仍存活的对象降低扫描频率，提高整体扫描效率。
