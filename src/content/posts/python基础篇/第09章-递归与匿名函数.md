## 9.1 递归的基本概念

**递归调用(recursion)**:在调用一个函数的过程中,又直接或间接调用了这个函数本身。
**结论**:递归的核心是"函数自己调用自己"。函数嵌套分两种——**定义时嵌套**(已经用在装饰器里)和**调用时嵌套**,递归就是调用时嵌套的典型用途。
```python
# 直接递归
def func():
    print('-' * 20)
    func()            # 在自己内部调用自己:局部没有 func,就去全局找到它再调用

# func()   # 会无限递归直到报错:第 2 次调用的 func 又调用了第 3 次,每次都结束不了
```

**间接递归**:你调用我、我调用你,本质和直接递归一样。
```python
def func1():
    print('func1')
    func2()

def func2():
    print('func2')
    func1()           # 又调回 func1

# func1()   # 同样无限递归
```

**递归 vs 普通死循环**:

| | 普通死循环 | 无限递归 |
|---|---|---|
| 内存占用 | 不会无休止申请内存 | 每层都申请新的局部名称空间,撑爆内存 |
| 原因 | 只有一份代码在重复执行 | 函数每调用一次产生一个局部名称空间,调用结束才回收;每层都结束不了,名称空间不断累积 |

`print('-' * 20); func()` 看起来像 `while True` 死循环,区别在于:**函数每调用一次都会产生一个独立的局部名称空间**,递归层数越深,占用内存越多。
所以 Python 对**递归深度**做了限制,默认 **1000 层**,超过会抛出 `RecursionError`(maximum recursion depth exceeded)。
```python
import sys

print(sys.getrecursionlimit())   # 1000,查看当前递归深度限制
sys.setrecursionlimit(1500)      # 可修改限制
print(sys.getrecursionlimit())   # 1500
```


:::warning[注意]
不要把递归深度限制改大。改大只是让递归能申请更多内存,并不能解决根本问题。而且 **Python 没有尾递归优化**——即使把进入下一层的调用写在 `return` 后面(尾递归写法),进入下一层前上一层的内存也不会被释放(有些语言会做这个优化)。正确做法是给递归设置**结束条件**,别去触碰深度限制。
:::

## 9.2 递归的结束条件

**结论**:递归本质是一种循环,必须有**出口**,否则就等价于无限循环。
做法很简单:递归调用本身就是函数调用,用一个 `if` 判断,满足条件时不再进入下一层递归——相当于给递归设置一个"结束信号"。
```python
def func(n):
    if n == 5:          # 结束条件:满足后不再进入下一层递归
        return
    print('第 %s 层' % n)
    func(n + 1)

func(1)
# 输出:
# 第 1 层
# 第 2 层
# 第 3 层
# 第 4 层
```

类比:递归像"剥洋葱",必须有一层是最后一层;没有结束条件的递归,就是在无限地往下剥。
## 9.3 递推与回归:计算 1 到 10 的和

需求:计算 1 到 10 的和。先用 `while` 循环实现:

```python
i = 10
total = 0
while i > 0:
    total += i      # total = total + i
    i -= 1
print(total)        # 55
```

**改成递归 - 初版(使用全局变量)**。递归就是循环:`while` 怎么做,递归就照着做,把循环体放进函数、在最后调用自己。此时 `total`、`i` 是全局的不可变类型,函数里修改要用 `global` 声明:

```python
i = 10
total = 0

def my_sum():
    global total, i
    if i == 0:          # 结束条件
        return
    total += i
    i -= 1
    my_sum()            # 在最后调用自己,形成"循环"

my_sum()
print(total)            # 55
```

**简化版(使用参数和返回值)**。三步简化:`i` 定义成形参 → `i -= 1` 直接写成 `my_sum(i - 1)` → 干脆让函数返回 `i + my_sum(i - 1)`,`total` 也就没用了。
```python
def my_sum(i):
    if i == 0:
        return 0              # 必须返回 0,不能只写 return(返回 None,无法和整数相加)
    return i + my_sum(i - 1)

print(my_sum(10))     # 55
print(my_sum(100))    # 5050
```

**执行过程分析**:

- **递推**:从外向内,一层层调用。`my_sum(10)` → `10 + my_sum(9)` → `9 + my_sum(8)` → ... → `1 + my_sum(0)`
- **回归(回溯)**:满足结束条件后,从内向外,一层层返回结果并结束调用。`my_sum(0)` 返回 0 → `my_sum(1)` 返回 1 → `my_sum(2)` 返回 3 → ... → `my_sum(10)` 返回 55

类比"问人":10 不知道答案,去问 9;9 去问 8……1 去问 0,0 直接返回 0(它不用再问了)。然后 1 告诉 2"我加到 0 是 1",2 告诉 3"我加到 0 是 3"……一层层把结果往外交,最后回到 10 得到 55。
**结论**:递归 = 递推 + 回归。递推负责"往下问",回归负责"把答案往回带"。
## 9.4 递归应用:处理嵌套列表

**需求**:取出任意层数嵌套列表中的每个值。
先用循环处理两层嵌套:

```python
l = ['a', 'b', ['c', 'd']]

for i in l:
    if type(i) is list:
        for j in i:
            if type(j) is list:
                pass          # 还是列表,就得再写一层循环……
            else:
                print(j)
    else:
        print(i)
```

**问题**:内层代码逻辑和外层**一模一样**,唯一区别只是遍历的对象不同(外层遍历 `l`,内层遍历 `i`)。层数未知时,列表有多少层就得写多少层循环——一段代码在运行过程中还需要"调用自己",这正是递归的用武之地。
**递归方案**:把代码放进函数,把要遍历的列表定义成参数,遇到列表就调用自己。
```python
def f(li):
    for i in li:
        if type(i) is list:   # 是列表:递归处理这个子列表
            f(i)
        else:                 # 不是列表:直接打印
            print(i, end=' ')

f(['a', 'b', ['c', 'd']])
print()                       # 换行
# 输出: a b c d

l = ['a', ['b', ['c', ['d', ['e', ['f', ['g']]]], 'h'], 'i']]
f(l)
# 输出: a b c d e f g h i
```

**结论**:递归的结束条件在这里是**隐含的**——一个列表里没有子列表时,`for` 循环走完,函数自然返回。不管套多少层,逻辑都不用改。

:::note[补充]
判断类型也可以用 `isinstance(i, list)`,它对列表的子类也返回 `True`。
:::

## 9.5 递归实战:全排列

**全排列(permutation)**:把 n 个元素按不同顺序排列,输出所有情况且不重复。
### 9.5.1 找规律

三个字母 ABC 的全排列:

```text
ABC  ACB     ← 固定 A,后面的 B、C 互换,对 BC 排列
BAC  BCA     ← A 和 B 换,以 B 开头,对 AC 排列
CBA  CAB     ← A 和 C 换,以 C 开头,对 BA 排列
```

**规律**:让第一个字符依次和每个字符(包括自己)互换,固定住它,然后对后面的数据做全排列。一组数据有多少个值,就可以分成多少类。
`ABCD` 就分四类:A 和 A 换固定 A,对 `BCD` 排列;A 和 B 换固定 B,对 `ACD` 排列;A 和 C 换固定 C,对 `BAD` 排列;A 和 D 换固定 D,对 `BCA` 排列。
第二轮对剩下的三个字符用同样的套路再分类……可以发现:**每一轮的逻辑都一样**,唯一区别是每一轮要排列的字符串长度不同——这是典型的递归场景。
### 9.5.2 关键:换回原样

画出完整的递归过程:

```text
第1层: 固定第0位, A 依次和 A/B/C/D 换 → ABCD  BACD  CBAD  DBCA
第2层: 以 ABCD 为例,固定 A,遍历 BCD   → ABCD  ACBD  ADCB
第3层: 以 ABCD 为例,固定 AB,遍历 CD   → ABCD  ABDC
第4层: 固定 ABC,只剩 D,只能和自己换   → 打印 ABCD
```

走完第 4 层打印 `ABCD` 后退回第 3 层,进行第 3 层的第二次循环(C 和 D 换),再进第 4 层打印 `ABDC`,然后退回第 2 层。
**关键问题**:第 2 层的第二次循环本应在 `ABCD` 的基础上把 B 和 C 换位,可经过刚才那条线回来之后,列表已经变成了 `ABDC`。所以**每次递归回来、进入下一次循环之前,必须把列表换回原样**。

:::warning[注意]
忘了"换回原样"是全排列最常见的 bug:第 2 层之后的所有排列都会基于错误的初始列表,结果错乱或重复。
:::

### 9.5.3 完整代码

**准备工作**:字符串不支持原地换位,先用 `list()` 转成列表;循环要按**索引**遍历,才能拿着索引去换位。
**换位的写法**:不能写 `l[0] = l[i]`,那样原来的值会被覆盖丢失。要同时取出两个值再交叉赋值:

```python
l = list('abcd')
i = 1
l[0], l[i] = l[i], l[0]   # 同时拿到 l[i] 和 l[0],再按位置分别赋回去
print(l)                  # ['b', 'a', 'c', 'd']
```

当 `i` 等于 0 时就是自己和自己换,值不变。
```python
def permutation(l, level):
    """
    l: 要做全排列的列表
    level: 本层从哪个索引开始遍历(前面 level 个字符已固定)
    """
    if level == len(l):                       # 没有可交换的了:得到一个排列
        print(''.join(l))
        return
    for i in range(level, len(l)):
        l[level], l[i] = l[i], l[level]       # 第 level 位依次和后面每一位互换
        permutation(l, level + 1)             # 递归:固定当前位,排列后面的部分
        l[level], l[i] = l[i], l[level]       # 换回原样,保证下次循环的基础不变

# 测试
l = list('abcd')
permutation(l, 0)
# 输出(共 24 种,无重复,每行一个):
# abcd abdc acbd acdb adcb adbc
# bacd badc bcad bcda bdca bdac
# cbad cbda cabd cadb cdab cdba
# dbca dbac dcba dcab dacb dabc

l = list('abc')
permutation(l, 0)
# 输出:
# abc acb bac bca cba cab
```

**推导思路**:当 `level` 等于 `len(l)` 时已经"没有可交换的字符了"——第 5 层 `range(4, 4)` 一次都不执行,函数会直接退回上一层。所以来到这一层就**把此时的 `l` 打印出来**,这就是一个排列结果。循环结束位置不能写死成 4,要写成 `len(l)`,功能才"写活"。

:::note[补充]
标准库 `itertools.permutations('abcd')` 可直接得到所有排列(元素为元组)。n 个元素的全排列有 n! 种,如 4!=24、5!=120,增长非常快。
:::

## 9.6 递归实战:二分法查找

**算法(algorithm)**:高效解决问题的方法,本质是一组解决问题的步骤。
**判断算法好坏看两方面**:消耗的**时间**和**资源**。类比做番茄炒蛋:做法可以有很多种,如果味道一样,用料少、耗时短的就是更好的算法。
**需求**:在一个升序排列的列表中查找指定数字。
普通做法——逐个比较:

```python
l = [1, 3, 5, 6, 8, 11, 15, 20, 23, 30]

for i in l:
    if i == 8:
        print('找到了')
        break
# 输出: 找到了
```

**问题**:列表很长且目标值在末尾时,要循环几十万次,效率很低。
**二分法思路**:

1. 前提:列表必须有序(可先用 `l.sort()` 排序)
2. 取列表中间值,与目标值比较
3. 目标值更大就切掉左半边,更小就切掉右半边
4. 对新列表重复同样操作(递归)
5. 结束条件:①中间值等于目标值(找到);②列表为空(不存在)

```python
def binary_search(find_num, l):
    print(l)                          # 显示当前查找范围,方便观察
    if len(l) == 0:                   # 结束条件1:切成空列表
        print('要找的值不存在')
        return
    mid_index = len(l) // 2           # 中间位置(整除)
    if find_num > l[mid_index]:
        binary_search(find_num, l[mid_index + 1:])   # 在右半边找
    elif find_num < l[mid_index]:
        binary_search(find_num, l[:mid_index])       # 在左半边找
    else:                             # 结束条件2:找到
        print('找到了', find_num)

l = [1, 3, 5, 6, 8, 11, 15, 20, 23, 30]
binary_search(8, l)
# 输出:
# [1, 3, 5, 6, 8, 11, 15, 20, 23, 30]
# [1, 3, 5, 6, 8]
# [6, 8]
# 找到了 8

binary_search(7, l)
# 输出:
# [1, 3, 5, 6, 8, 11, 15, 20, 23, 30]
# [1, 3, 5, 6, 8]
# [6, 8]
# [6]
# []
# 要找的值不存在
```

每递归一次,列表长度缩减一半,查找效率大大提升。100 万个有序数最多只需比较约 20 次(2²⁰≈100 万)。
**优化:双指针法(不复制列表)**

上面的写法每次切片都会复制一份新列表;实际开发中更常用"左右两个下标"的循环写法:

```python
def binary_search2(find_num, l):
    low, high = 0, len(l) - 1          # 查找范围的左右边界
    while low <= high:
        mid = (low + high) // 2
        if find_num > l[mid]:
            low = mid + 1              # 去右半边
        elif find_num < l[mid]:
            high = mid - 1             # 去左半边
        else:
            return mid                 # 找到,返回索引
    return -1                          # 找不到

l = [1, 3, 5, 6, 8, 11, 15, 20, 23, 30]
print(binary_search2(8, l))   # 4
print(binary_search2(7, l))   # -1
```


:::note[补充]
标准库 `bisect` 模块提供了现成的二分查找工具:`bisect.bisect_left()`、`bisect.bisect_right()` 等。
:::

## 9.7 匿名函数 lambda 的定义

**匿名函数(anonymous function)**:没有函数名的函数,用关键字 `lambda` 定义。`def` 后面必须跟函数名,所以定义匿名函数不能用 `def`。
```python
# 有名函数
def func(x, y):
    return x + y

# 匿名函数
lambda x, y: x + y
```

**lambda 语法特点**

- 参数后面**不用括号**,参数可以有默认值,如 `y=1`
- 冒号后面直接写返回值表达式,写在一行,不回车——所以匿名函数也叫 **lambda 表达式**
- **不用写 `return`**,表达式的值自动返回

```python
print(lambda x, y=1: x + y)
# 输出: <function <lambda> at 0x...>   就是一个函数的内存地址
```

**调用方式**:匿名函数没有名字,但肯定有内存地址。用小括号把整个 lambda 括起来,后面再加括号传参:

```python
res = (lambda x, y=1: x + y)(1, 2)   # 直接写 lambda ... (1, 2) 会被理解成对 y 加括号
print(res)   # 3

res = (lambda x, y=1: x + y)(1)      # y 有默认值,可以只传一个参数
print(res)   # 2
```


:::warning[注意]
直接写 `lambda x, y=1: x + y(1, 2)` 会被解析成 `x + y(1, 2)`,即把 `y` 当函数调用,而不是调用整个 lambda。必须先给整个 lambda 加括号。
:::

**能赋值给变量吗?** 可以,但**违背了匿名函数的初衷**。
```python
func = lambda x, y=1: x + y
print(func(1))   # 2
# 不推荐:有名字的需求直接用 def 定义有名函数就好
```

**匿名函数的应用场景**:匿名函数定义出来只是一个没绑定任何名字的内存地址,引用计数为 0,**定义完立刻被当作垃圾回收**。所以它应该在定义的那一刻就被调用一次,用完即回收。

- 有名函数:用于需要**重复调用**的功能
- 匿名函数:用于**只需临时调用一次**的功能,**一般和其他函数配合使用**

**函数体可以写别的代码吗?** 可以,但返回值就变成了那条语句的返回值。比如写 `print(x + y)`,返回值就是 `print` 的返回值 `None`,一般不这么用,函数体通常写一个**表达式**。
```python
res = (lambda x, y: print(x + y))(1, 2)   # 打印 3
print(res)                                # None
```

## 9.8 匿名函数配合 max、min

**需求**:找出薪资最高的人——比较的是字典的**值**(薪资),要得到的却是**键**(名字)。
先看内置函数 `max`:接收可迭代对象,依次取值,比较本次值和上次留下的值,留下大的,最后返回最大值。
```python
print(max([3, 9, 6, 10]))   # 10
```

直接对字典用 `max`:

```python
info = {
    'tony': 2500,
    'alice': 8000,
    'jack': 6000,
    'lucy': 11000,
}

print(max(info))   # tony  —— 薪资最高的明明是 lucy
```

**原因**:`max` 默认用迭代出来的值作为比较依据,而字典迭代取出的是 **key**,于是它把名字字符串拿来比大小。字符串按字符编码表逐个字符比较:`t`(116) > `l`(108) > `j`(106) > `a`(97),所以结果是 tony。
**用 `key` 参数指定比较依据**:`key` 接收一个**函数的内存地址**,`max` 每迭代一次就自动调用这个函数,把迭代出的值传进去,**用返回值作为比较依据**,最终返回的仍是迭代出的值。
```python
info = {'tony': 2500, 'alice': 8000, 'jack': 6000, 'lucy': 11000}

def func(k):
    return info[k]        # 返回对应薪资作为比较依据

print(max(info, key=func))   # lucy
# 注意只传函数名(内存地址),不要加括号;加括号就是立刻调用它了
```

`func` 功能非常局限,`max` 执行完就再也用不到了——它就是临时用一次的函数,正适合改成匿名函数:

```python
info = {'tony': 2500, 'alice': 8000, 'jack': 6000, 'lucy': 11000}

print(max(info, key=lambda k: info[k]))   # lucy
print(min(info, key=lambda k: info[k]))   # tony,min 用法与 max 完全一样
```

**结论**:这就是匿名函数真正的应用场景——和其他函数配合使用,那个函数执行完之后,匿名函数也就没有存在的意义了。
## 9.9 匿名函数配合 sort、sorted

**列表的 `sort` 方法**:默认**升序**,`reverse=True` 降序(默认 `reverse=False`)。
```python
l = [3, 1, 2]
l.sort()
print(l)               # [1, 2, 3]
l.sort(reverse=True)
print(l)               # [3, 2, 1]
```

列表里是元组时,想按每个元组的**第二个值**排序,同样用 `key` 指定比较依据:

```python
l = [('a', 3), ('b', 1), ('c', 2)]
l.sort(key=lambda item: item[1])   # item 是迭代出的小元组,item[1] 是它的第二个值
print(l)   # [('b', 1), ('c', 2), ('a', 3)]
```

**内置函数 `sorted`**:用法和 `max`、`min` 一模一样,可对任意可迭代对象排序。
```python
info = {'tony': 2500, 'alice': 8000, 'jack': 6000, 'lucy': 11000}

print(sorted(info, key=lambda k: info[k]))                 # 按薪资升序
# 输出: ['tony', 'jack', 'alice', 'lucy']
print(sorted(info, key=lambda k: info[k], reverse=True))   # 按薪资降序
# 输出: ['lucy', 'alice', 'jack', 'tony']
```


:::note[补充]
`l.sort()` 直接修改原列表、返回 `None`;`sorted()` 返回**新列表**,不修改原对象。对字典只能用 `sorted`,因为字典没有 `sort` 方法。
:::

## 9.10 匿名函数配合 map、filter、reduce

**map 映射**:对可迭代对象的每个元素应用函数,返回迭代器。
需求:给列表里每个值都加上 `_老坛酸菜`。列表生成式就能做:

```python
l = ['Kevin', 'Tom', 'Jack']

new_l = [name + '_老坛酸菜' for name in l]
print(new_l)   # ['Kevin_老坛酸菜', 'Tom_老坛酸菜', 'Jack_老坛酸菜']
```

`map` 也能做:第一个参数传一个函数(处理数据的**规则**),第二个参数传可迭代对象。
```python
l = ['Kevin', 'Tom', 'Jack']

res = map(lambda name: name + '_老坛酸菜', l)
print(res)              # <map object at 0x...>   不明文显示结果
print(next(res))        # Kevin_老坛酸菜   逐个取值
print(list(res))        # ['Tom_老坛酸菜', 'Jack_老坛酸菜']   取剩下的
```

**结论**:`map` 返回的是一个**迭代器**(map 对象,常被叫作"生成器",严格来说是迭代器),用一个取一个,节省内存。
**filter 过滤**:保留函数返回值为真的元素。
```python
print(list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4])))   # [2, 4]
```

**reduce 合并**:两两合并成一个值,Python 3 中需从 `functools` 导入。
```python
from functools import reduce

print(reduce(lambda x, y: x + y, [1, 2, 3], 10))   # 16
# 10 + 1 = 11,11 + 2 = 13,13 + 3 = 16
```


:::tip[技巧]
`map`、`filter`、`reduce` 的对比:map 一对一变(元素个数不变)、filter 留下符合条件的、reduce 多对一变(合并成一个值)。
:::

## 9.11 函数的类型提示

先看问题:Python 函数的参数限制不了类型。
```python
def func(name, age):
    print(name, age)
    return 10

func(3.14, [1, 2, 3])   # 本意 name 传字符串、age 传整数,但传什么类型都可以
# 输出:
# 3.14 [1, 2, 3]
```

这是 Python 语言的特点决定的——**Python 是解释型、强类型、动态语言**。
| 分类 | 含义 | Python 属于 |
|---|---|---|
| 编译型 / 解释型 | 编译型先整体编译成机器码再运行;解释型边解释边执行 | 解释型 |
| 强类型 / 弱类型 | 强类型数据不可被忽略,换类型必须显式转换;弱类型(如 PHP、JS)可随意切换 | 强类型 |
| 动态型 / 静态型 | 动态型定义变量时不规定类型,赋值后才确定;静态型定义时就要规定类型 | 动态型 |

```python
print('1' + str(2))   # 强类型:字符串和整数不能直接相加,必须显式转换
# 输出: 12
```

**动态性的利与弊**:不用像其他语言那样在参数后写死类型声明,代码更精简;但缺点是**提示性不够**。Python 的风格是"通过规范告诉你应该怎么做",而不是"不遵守就报错"。
**类型提示**(type hints,Python 3.5+):提示参数和返回值的类型,但**不强制**。

- 参数:在形参后加冒号和类型,如 `name: str`、`age: int`
- 返回值:在括号后、冒号前写 `->` 再写类型,如 `-> int`

```python
def func(name: str, age: int) -> int:
    print(name, age)
    return 10

func(3.14, [1, 2, 3])   # 照样不报错
# 输出:
# 3.14 [1, 2, 3]
```

**类型提示 + 默认值**:把类型提示理解成"当 `: int` 不存在",就是普通的默认参数。注意等号**不能写在类型前面**。
```python
def func(name: str, age: int = 88) -> int:   # age 默认值为 88
    print(name, age)
    return 10

func('Tom')
# 输出: Tom 88

# def func(name: str, age = 88: int):   # 错误写法:等号写在类型前面会报语法错误
```

**查看提示信息**:`函数名.__annotations__`。
```python
def func(name: str, age: int = 88) -> int:
    return 10

print(func.__annotations__)
# {'name': <class 'str'>, 'age': <class 'int'>, 'return': <class 'int'>}
```


:::warning[注意]
类型提示只是**提示**,写完再运行,传错类型照样不报错。想在开发时真正检查类型,可以用 `mypy` 工具,PyCharm 也会对传错类型的地方给出警告。
[!note] 补充
更细致的写法:Python 3.9+ 可写 `list[int]`、`dict[str, int]` 标明元素类型;Python 3.10+ 可用 `int | str` 表示"多种类型之一";`-> None` 表示无返回值。
:::

## 本章小结

- **递归调用**:函数直接或间接调用自身,本质是一种循环。每次调用产生一个新的局部名称空间,Python 限制递归深度默认 1000 层,可用 `sys.getrecursionlimit()` / `sys.setrecursionlimit()` 查看和修改,但**不建议修改**。
- Python **没有尾递归优化**,递归必须用 `if` 设置**结束条件**,不要去触碰深度限制。
- **递推与回归**:递推是从外向内一层层调用,回归是满足条件后从内向外一层层返回结果;递归 = 递推 + 回归。
- **嵌套列表**:层数不确定时用递归,逻辑不随层数变化,结束条件是隐含的(没有子列表时循环自然结束)。
- **全排列**:第 `level` 位依次与后面每一位交换 → 递归排列后面的部分 → **换回原样**;`level == len(l)` 时输出。n 个元素有 n! 种排列。
- **算法**是高效解决问题的方法。**二分法**要求序列有序,每次与中间值比较并切掉一半,时间复杂度 O(log n),远快于逐个比较。
- **lambda 匿名函数**:`lambda 参数: 表达式`,无函数名、参数不加括号、写在一行、自带 return;调用要先用括号把整个 lambda 括起来。适合临时用一次,通常与其他函数配合。
- **key 参数**:`max`、`min`、`sort`、`sorted` 的 `key` 接收一个函数(只传函数名,不加括号),每迭代一次调用一次,用返回值作比较依据;`reverse=True` 降序。
- **map 映射 / filter 过滤 / reduce 合并**:`map(函数, 可迭代对象)` 返回迭代器;reduce 需 `from functools import reduce`。
- **类型提示**:`def f(x: int, y: int = 1) -> int:` 只提示不强制,可用 `__annotations__` 查看。Python 是解释型、强类型、动态语言。

        return

    if find_num > l[mid]:
        return search_count(find_num, l[mid + 1:], count + 1)
    elif find_num < l[mid]:
        return search_count(find_num, l[:mid], count + 1)
    return '找到了,共比较%d次' % count
