## 4.1 数字类型

### 4.1.1 参数与返回值

**名字加括号 = 触发功能。** `print()`、`input()`、`int()` 都一样:只要是一个名字加上括号,就表示触发了一个功能的运行。括号里传的东西叫**参数**,功能交还的结果叫**返回值**。
类比:把功能想象成工厂——参数是原材料,返回值是产品。
```python
age = int(84)          # int 是功能,84 是参数,返回整型值
print(age, type(age))  # 输出: 84 <class 'int'>

res = print('hello')   # print 没有返回值
print(res)             # 输出: None
```

**结论**:`age = 84` 背后其实是 `age = int(84)`。有的功能有返回值(如 `input`、`int`),有的没有(如 `print`)。
### 4.1.2 类型转换

`int()` 和 `float()` 除了能造自己的类型,还能做类型转换:

```python
# int 转换
print(int('123'))      # 字符串 → 整型,输出: 123
print(int(3.99))       # 浮点 → 整型,直接舍弃小数,输出: 3
# int('3.14')          # 报错:带小数点的字符串不能转

# float 转换
print(float('3'))      # 输出: 3.0
print(float('3.14'))   # 带小数点的字符串也可以,输出: 3.14
```

**区别**:`int()` 不能转带小数点的字符串,`float()` 可以。
### 4.1.3 进制与转换

**进制规则**

| 进制 | 规则 | 符号 | 示例 |
|---|---|---|---|
| 十进制 | 满十进一 | 0~9 | 10、99、100 |
| 二进制 | 满二进一 | 0、1 | 10(2)、11(3)、100(4) |
| 八进制 | 满八进一 | 0~7 | 10(8)、17(15)、20(16) |
| 十六进制 | 满十六进一 | 0~9、A~F | 10(16)、FF(255)、100(256) |

**换算方法**

1. **其他进制 → 十进制**:按位权展开

```python
# 二进制 1101 转十进制
# 1×2⁰ + 0×2¹ + 1×2² + 1×2³ = 1 + 0 + 4 + 8 = 13

# 十六进制 36d 转十进制
# 13×16⁰ + 6×16¹ + 3×16² = 13 + 96 + 768 = 877
```

2. **十进制 → 其他进制**:连除法,余数反向排列

```python
# 十进制 35 → 二进制
# 35÷2=17…1, 17÷2=8…1, 8÷2=4…0, 4÷2=2…0, 2÷2=1…0, 1÷2=0…1
# 反向排列:100011
```

3. **二进制快速转换**
- 二进制 ↔ 八进制:每 3 位一组(2³=8)
- 二进制 ↔ 十六进制:每 4 位一组(2⁴=16)

```python
# 11011011 → 八进制:011 011 011 → 333
# 11011011 → 十六进制:1101 1011 → DB
```

**Python 进制转换**

```python
# 十进制 → 其他进制
print(bin(12))         # 输出: 0b1100
print(oct(12))         # 输出: 0o14
print(hex(12))         # 输出: 0xc

# 其他进制 → 十进制
print(int('0b1100', 2))   # 输出: 12
print(int('0o14', 8))     # 输出: 12
print(int('0xc', 16))     # 输出: 12
```


:::tip[技巧]
Python 可直接用前缀定义不同进制:`0b` 二进制、`0o` 八进制、`0x` 十六进制。打印时默认显示为十进制。
:::

## 4.2 字符串详解

### 4.2.1 定义与类型转换

定义字符串背后调用的是 `str()`,它能把**任意类型**转成字符串——相当于在值两边加引号:

```python
name = '梦泪'                    # 背后相当于 name = str('梦泪')
print(type(name))                  # 输出: <class 'str'>

print(str([1, 2, 3]))              # 输出: [1, 2, 3]
print(str({'name': '梦泪'}))     # 输出: {'name': '梦泪'}
```

### 4.2.2 索引与切片

**索引取值**

字符串由多个字符按顺序组成,可以按索引取值,但**不能按索引改值**(字符串是不可变类型):

```python
info = 'good good study'
print(info[0])         # 输出: g
print(info[-1])        # 反向索引,输出: y
# info[0] = 'G'        # 报错:字符串不可变
```

**切片操作**

语法:`字符串[起始:结束:步长]`,顾头不顾尾,是复制而非剪切。
```python
info = 'good good study'
print(info[0:4])       # 输出: good
print(info[0:])        # 从 0 开始到末尾,输出完整字符串
print(info[:4])        # 从开头到 4,输出: good
print(info[0:20:3])    # 步长为 3,输出: gdo u
print(info[::-1])      # 反向步长,字符串倒序,输出: yduts doog doog
```


:::warning[注意]
反向步长时起止方向也要反过来,如 `info[4:0:-1]` 从 4 号往左取到 1 号。
:::

### 4.2.3 常用方法

**strip 系列:去除两端字符**

```python
name = '   梦泪   '
print(name.strip())          # 去两端空格,输出: 梦泪
print(name.lstrip())         # 只去左边,输出: '梦泪   '
print(name.rstrip())         # 只去右边,输出: '   梦泪'

name = '!!!梦泪!!!'
print(name.strip('!'))       # 去两端指定字符,输出: 梦泪
```

**split/rsplit:拆分**

```python
names = '李白 韩信 露娜 孙悟空'
print(names.split())         # 默认按空格拆,输出: ['李白', '韩信', '露娜', '孙悟空']

names = '李白-韩信-露娜-孙悟空'
print(names.split('-'))      # 按 - 拆分,输出: ['李白', '韩信', '露娜', '孙悟空']
print(names.split('-', 1))   # 拆 1 次,输出: ['李白', '韩信-露娜-孙悟空']
print(names.rsplit('-', 1))  # 从右往左拆 1 次,输出: ['李白-韩信-露娜', '孙悟空']
```

**join:拼接**

```python
l = ['李白', '杜甫', '白居易', '陶渊明']
print('-'.join(l))           # 输出: 李白-杜甫-白居易-陶渊明
# 注意:join 是字符串方法,不是列表方法;列表元素必须都是字符串
```

**其他常用方法**

```python
msg = 'AbCd'
print(msg.lower())                    # 转小写,输出: abcd
print(msg.upper())                    # 转大写,输出: ABCD

poem = '君不见黄河之水天上来'
print(poem.startswith('君不见'))       # 输出: True
print(poem.endswith('不复回'))         # 输出: False

names = '李白-杜甫-白居易'
print(names.replace('-', ':'))        # 全部替换,输出: 李白:杜甫:白居易
print(names.replace('-', ':', 1))     # 只替换 1 次,输出: 李白:杜甫-白居易

print('84'.isdigit())                 # 判断是否纯数字,输出: True
print('8.4'.isdigit())                # 有小数点,输出: False
```

**长度与成员运算**

```python
info = 'good good study'
print(len(info))              # 统计字符数,输出: 15
print('good' in info)         # 输出: True
print('bad' not in info)      # 输出: True
```


:::note[补充]
字符串的所有方法都不修改原字符串,而是返回新字符串。PyCharm 参数提示中的 `self` 当它不存在。
:::

### 4.2.4 应用案例

**猜数字游戏**

```python
while True:
    num = input('请输入你猜的数字:').strip()
    if not num.isdigit():
        print('别调皮,要输入纯数字')
        continue
    num = int(num)
    if num > 36:
        print('猜大了')
    elif num < 36:
        print('猜小了')
    else:
        print('猜对了')
        break
```

**优化登录**

```python
# 用户输入时可能前后多空格,用 strip 处理
inp_username = input('请输入账号:').strip()
inp_password = input('请输入密码:').strip()

if inp_username == '130354500' and inp_password == '123456':
    print('登录成功')
else:
    print('账号密码错误')
```

## 4.3 列表与元组

### 4.3.1 列表的创建与转换

列表可以按位置存放多个任意类型的值:

```python
msg = ['梦泪', 84, 1.88, False]
print(type(msg))                      # 输出: <class 'list'>

# 类型转换:能被 for 循环遍历的类型都能转成列表
print(list('hello'))                  # 输出: ['h', 'e', 'l', 'l', 'o']
print(list({'a': 1, 'b': 2}))         # 字典转出 key,输出: ['a', 'b']
```

### 4.3.2 索引与增加值

**索引取值与改值**

```python
l = ['李星云', '姬如雪', '张子凡']
print(l[1])          # 输出: 姬如雪
l[1] = '九天圣姬'     # 改值
print(l)             # 输出: ['李星云', '九天圣姬', '张子凡']
```


:::warning[注意]
按索引改值必须是已存在的索引,不存在会报 `IndexError`。
:::

**append:末尾追加**

```python
l = ['李星云', '姬如雪']
l.append(5)
l.append(6)
print(l)             # 输出: ['李星云', '姬如雪', 5, 6]
```

**insert:指定位置插入**

```python
l = ['李星云', '姬如雪']
l.insert(2, '李淳风')    # 插到索引 2 的位置
print(l)                 # 输出: ['李星云', '姬如雪', '李淳风']
l.insert(0, '李淳风')    # 插到开头
print(l)                 # 输出: ['李淳风', '李星云', '姬如雪', '李淳风']
```

**extend:合并列表**

```python
l1 = ['李星云', '姬如雪']
l2 = ['梵音天', '妙成天', '玄净天']
l1.extend(l2)            # 把 l2 的每个值单独加进 l1
print(l1)                # 输出: ['李星云', '姬如雪', '梵音天', '妙成天', '玄净天']
```


:::note[补充]
`l1 + l2` 生成新列表,`l1` 不变;`l1.extend(l2)` 直接修改 `l1`,返回 `None`。
:::

### 4.3.3 删除值

| 方式 | 依据 | 返回值 |
|---|---|---|
| `del 列表[索引]` | 索引 | 无(通用删除语句) |
| `列表.pop(索引)` | 索引(默认最后) | 被删除的值 |
| `列表.remove(值)` | 值 | `None` |

```python
names = ['美杜莎', '云韵', '薰儿', '雅妃']

del names[0]
print(names)             # 输出: ['云韵', '薰儿', '雅妃']

names = ['美杜莎', '云韵', '薰儿', '雅妃']
res = names.pop()        # 删除并返回最后一个
print(res, names)        # 输出: 雅妃 ['美杜莎', '云韵', '薰儿']

names = ['美杜莎', '云韵', '薰儿', '雅妃']
names.remove('美杜莎')
print(names)             # 输出: ['云韵', '薰儿', '雅妃']
```

### 4.3.4 其他操作

**切片、长度、成员运算**

```python
names = ['美杜莎', '云韵', '薰儿', '雅妃']
print(names[0:2])              # 切片,输出: ['美杜莎', '云韵']
print(len(names))              # 输出: 4
print('云韵' in names)          # 输出: True
```


:::warning[注意]
不能一边用 for 遍历列表,一边在循环体里修改这个列表,会导致循环次数异常。
:::

**count、index、clear、reverse**

```python
names = ['美杜莎', '云韵', '薰儿', '雅妃', '云韵', '云韵']
print(names.count('云韵'))     # 统计出现次数,输出: 3
print(names.index('云韵'))     # 查找索引,输出: 1

names.clear()                  # 清空
print(names)                   # 输出: []

names = ['美杜莎', '云韵', '薰儿', '雅妃']
names.reverse()                # 反转(直接修改原列表)
print(names)                   # 输出: ['雅妃', '薰儿', '云韵', '美杜莎']
```

**sort:排序**

```python
l = [55, 66, 33, 99]
l.sort()                       # 升序(默认)
print(l)                       # 输出: [33, 55, 66, 99]
l.sort(reverse=True)           # 降序
print(l)                       # 输出: [99, 66, 55, 33]
```

- `reverse=True` 是**关键字参数**,区别于按位置传的**位置参数**。
- 能排序的前提:元素之间能比大小。字符串比大小按 ASCII 码逐位比,列表同理。
### 4.3.5 队列与堆栈

队列和堆栈是两种数据结构,区别在于数据进出的顺序。
**队列:先进先出(FIFO)**

```python
l = []
l.append('张三')
l.append('李四')
l.append('王五')

print(l.pop(0))    # 从队首出队,输出: 张三
print(l.pop(0))    # 输出: 李四
print(l.pop(0))    # 输出: 王五
```

**堆栈:后进先出(LIFO)**

```python
l = []
l.append('张三')
l.append('李四')
l.append('王五')

print(l.pop())     # 从队尾出栈,输出: 王五
print(l.pop())     # 输出: 李四
print(l.pop())     # 输出: 张三
```


:::note[补充]
实际开发中实现队列推荐用 `collections.deque`,用 `append()` 入队、`popleft()` 出队,性能更好。
:::

### 4.3.6 元组

**元组是不可变的列表**,定义用小括号,可以按索引取值但不能改值。
```python
t = (1, 3.14, 'abc', [1, 2])
print(type(t))         # 输出: <class 'tuple'>

# 易错点:只有一个元素时必须加逗号
t1 = (10)
print(type(t1))        # 输出: <class 'int'> (变成了整型)
t2 = (10,)
print(type(t2))        # 输出: <class 'tuple'>
```

**"不可变"的真正含义**

元组里存的是内存地址,地址不可变。如果元组里有可变类型(列表、字典),可以修改它们的内部值:

```python
x = (36, 'd', 1.68, ['a', 'b', 'c'])
# x[3] = [1, 2]        # 报错:不能替换地址
x[3][0] = 'd'          # 可以:改的是列表内部的值
print(x)               # 输出: (36, 'd', 1.68, ['d', 'b', 'c'])
```

**为什么用元组**

只读的数据用元组更省空间。元组方法只有 `index` 和 `count`,其他操作(索引、切片、`len`、`in`、`for`)与列表相同。
```python
msg = ('木', '火', '土', '金', '水', '火')
print(msg.index('土'))     # 输出: 2
print(msg.count('火'))     # 输出: 2
print(msg[::-1])           # 输出: ('水', '金', '土', '火', '木')
```

## 4.4 字典与集合

### 4.4.1 字典的创建

字典在大括号内用 `key: value` 形式存放键值对。**value 可以是任意类型,key 只能是不可变类型**(整型、浮点型、字符串、元组)。
**方式一:直接用大括号**

```python
d = {'name': 'egon', 1: 'int', 1.5: 'float', (1, 2): 'tuple'}
print(type(d))         # 输出: <class 'dict'>
```

**方式二:dict() 传入大括号或关键字参数**

```python
d = dict({'a': 1, 'b': 2})
print(d)               # 输出: {'a': 1, 'b': 2}

d = dict(a=1, b=2, c=3)
print(d)               # 输出: {'a': 1, 'b': 2, 'c': 3}
```

**方式三:fromkeys 快速初始化**

```python
keys = ['name', 'gender', 'age']
d = dict.fromkeys(keys, None)
print(d)               # 输出: {'name': None, 'gender': None, 'age': None}
```


:::warning[注意]
`fromkeys` 的第二个参数不要用可变类型,否则所有 key 会指向同一个对象。
:::

**类型转换**

```python
l = [('name', 'egon'), ['age', 18]]
print(dict(l))         # 输出: {'name': 'egon', 'age': 18}
# 要求:可迭代对象中每个元素都是"成对"的两个值
```

### 4.4.2 字典的增删改查

**按 key 取值、改值、增值**

```python
dic = {'a': 1, 'b': 2, 'c': 3}
print(dic['a'])        # 取值,输出: 1
dic['a'] = 11          # key 存在 → 修改
dic['d'] = 4           # key 不存在 → 新增
print(dic)             # 输出: {'a': 11, 'b': 2, 'c': 3, 'd': 4}
```

**字典的 key 是唯一的**,重复的 key 只保留最后一个值。
**get:安全取值**

```python
dic = {'a': 1, 'b': 2, 'c': 3}
print(dic.get('a'))       # 输出: 1
print(dic.get('x'))       # key 不存在返回 None,输出: None
print(dic.get('x', 0))    # 设置默认值,输出: 0
# print(dic['x'])         # 报错 KeyError
```

**删除:del、pop、popitem、clear**

```python
dic = {'a': 1, 'b': 2, 'c': 3}
del dic['a']
print(dic)                # 输出: {'b': 2, 'c': 3}

dic = {'a': 1, 'b': 2, 'c': 3}
res = dic.pop('a')        # 删除并返回值
print(res, dic)           # 输出: 1 {'b': 2, 'c': 3}

res = dic.popitem()       # 删除最后一对,返回 (key, value)
print(res, dic)           # 输出: ('c', 3) {'b': 2}

dic.clear()               # 清空
print(dic)                # 输出: {}
```

**len 与 in**

```python
dic = {'a': 1, 'b': 2, 'c': 3}
print(len(dic))           # 统计键值对个数,输出: 3
print('a' in dic)         # in 判断 key,输出: True
print(1 in dic)           # 1 是 value,输出: False
```

### 4.4.3 keys、values、items

Python3 中这三个方法返回的是"老母鸡"(类似 range),不会一次性生成列表,更省内存:

```python
dic = {'a': 1, 'b': 2}
print(dic.keys())         # 输出: dict_keys(['a', 'b'])
print(dic.values())       # 输出: dict_values([1, 2])
print(dic.items())        # 输出: dict_items([('a', 1), ('b', 2)])
```

**解压赋值**

```python
name, age = ('梦泪', 18)    # 解压赋值
print(name, age)              # 输出: 梦泪 18

# items 配合 for 循环
for key, value in dic.items():
    print(key, value)
# 输出:
# a 1
# b 2
```

### 4.4.4 update 与 setdefault

**update:更新字典**

```python
hero = {'名字': '李白', '职业': '刺客', '攻速': 130}
new = {'攻速': 120, '技能1': '将进酒'}
hero.update(new)    # 有则改,无则加
print(hero)
# 输出: {'名字': '李白', '职业': '刺客', '攻速': 120, '技能1': '将进酒'}
```

**setdefault:设置默认值**

```python
info = {'name': '梦泪', 'age': 18}
print(info.setdefault('age'))          # age 存在,返回原值,输出: 18
print(info.setdefault('gender'))       # gender 不存在,添加并返回 None
print(info)                            # 输出: {'name': '梦泪', 'age': 18, 'gender': None}

info = {'name': '梦泪', 'age': 18}
info.setdefault('gender', '保密')       # 指定默认值
print(info)                            # 输出: {'name': '梦泪', 'age': 18, 'gender': '保密'}
```

### 4.4.5 集合

**集合是去重和关系运算的数据类型**,元素必须不可变、不重复、无序,不能按索引取值。
```python
s = {1, 2, 3, 1, 1}
print(s)               # 重复元素只保留一个,输出: {1, 2, 3}

# 空集合用 set()
print(type({}))        # 输出: <class 'dict'>
print(type(set()))     # 输出: <class 'set'>

# 类型转换
print(set([1, 1, 2]))  # 输出: {1, 2}
```

**关系运算**

```python
hobbies1 = {'吃饭', '睡觉', '看书', '钢琴', '跳舞'}
hobbies2 = {'吃饭', '睡觉', '追剧', '打游戏'}

# 交集 &:共同的
print(hobbies1 & hobbies2)     # 输出: {'吃饭', '睡觉'}

# 并集 |:所有的(去重)
print(hobbies1 | hobbies2)

# 差集 -:独有的(有方向)
print(hobbies1 - hobbies2)     # 输出: {'看书', '钢琴', '跳舞'}
print(hobbies2 - hobbies1)     # 输出: {'追剧', '打游戏'}

# 对称差集 ^:各自独有的
print(hobbies1 ^ hobbies2)

# 父子集
s1 = {1, 2, 3}
s2 = {1, 2}
print(s1 > s2)         # s1 是父集,输出: True
print(s2 < s1)         # s2 是子集,输出: True
```

**常用方法**

```python
s = {1, 2, 3, 4}
s.add(6)               # 添加单个元素
print(s)               # 输出: {1, 2, 3, 4, 6}

s.remove(4)            # 删除指定元素(不存在会报错)
s.discard(5)           # 删除指定元素(不存在不报错)

s.update([5, 6], 'ab') # 批量添加可迭代对象的元素
print(s)

s1 = {1, 2, 3}
s2 = {4, 5, 6}
print(s1.isdisjoint(s2))   # 判断是否没有交集,输出: True
```

**集合去重的局限**

1. 无法保证原来的顺序
2. 只能针对不可变类型

```python
l = ['a', 'd', 'a', 'b']
print(set(l))          # 去重但顺序不保证

# 对可变类型去重且保留顺序
info = [[1, 2], [3, 4], [1, 2]]
new_info = []
for i in info:
    if i not in new_info:
        new_info.append(i)
print(new_info)        # 输出: [[1, 2], [3, 4]]
```

### 4.4.6 数据类型总结

**按存值个数分**

| 分类 | 类型 |
|---|---|
| 容器类型 | 列表、元组、字典、集合 |
| 标量/原子类型 | 整型、浮点型、字符串 |

**按可变性分**

| 分类 | 类型 |
|---|---|
| 可变类型(值变 id 不变) | 列表、字典、集合 |
| 不可变类型 | 整型、浮点型、字符串、元组 |

**按访问方式分**

| 分类 | 类型 | 说明 |
|---|---|---|
| 直接访问 | 整型、浮点型 | 通过变量名访问 |
| 顺序访问(序列) | 字符串、列表、元组 | 通过索引访问 |
| key 访问(映射) | 字典 | 通过 key 访问 |
| 只能整体访问 | 集合 | 不能取单个值 |


:::note[补充]
只有不可变类型才能做字典的 key 和集合的元素,因为它们是可哈希的(hashable)。
:::

## 本章小结

- **数字类型**:参数与返回值概念;`int()`、`float()` 类型转换;进制规则与转换(按位权展开、连除法、分组法)。
- **字符串**:索引取值(不能改值);切片(顾头不顾尾、反向步长);`strip`/`split`/`join` 等方法;所有方法都返回新字符串。
- **列表**:按索引取值改值;增(`append`/`insert`/`extend`);删(`del`/`pop`/`remove`);`sort`、`reverse`、`count`、`index`;遍历时不要修改列表;队列(FIFO)与堆栈(LIFO)。
- **元组**:不可变列表,单元素加逗号;不可变指地址不变;只读数据用元组更省空间;方法只有 `index`、`count`。
- **字典**:key 不可变且唯一,value 任意;按 key 取改增;`get` 安全取值;`keys/values/items` 配合解压赋值;`update` 有则改无则加;`setdefault` 设置默认值。
- **集合**:元素不可变、不重复、无序;关系运算(交 `&`、并 `|`、差 `-`、对称差 `^`、父子集 `>` `<`);去重不保序且只对不可变类型有效。
- **数据类型分类**:按存值个数、可变性、访问方式三个维度。
