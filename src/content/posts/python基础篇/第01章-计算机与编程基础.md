## 1.1 为什么要学 Python

要不要学 Python，首先要**理性思考、有自己的主见**，不要被别人的只言片语左右。判断一门语言的前景，可以看两类客观事实：

**1. 权威排行榜**：在 TIOBE 编程语言排行榜上，Python 在 2021 年已经跃居世界第一。

**2. 国家政策**：

- 浙江省将 Python 列入高考内容
- 教育大省北京、山东确定把 Python 编程基础纳入信息技术课程和高考内容体系
- 各地中小学也在推广 Python，山东省最新出版的小学信息技术教材已加入 Python 内容

类比历史：改革开放时期，国家在高考里加入了**英语**。当时很多人不理解，但今天还有人敢说英语没用吗？**高考是国家选拔人才的重要途径，往高考里加东西，就意味着国家要为这个领域储备人才。**

**Python 本身的优点**：

- 语法简洁、接近英语
- 应用领域广：Web 开发、爬虫、数据分析、人工智能、自动化运维与办公自动化等
- 第三方库丰富，很多功能"别人写好了拿来就能用"

## 1.2 编程语言是什么

**Python 就是一门编程语言（programming language）**。语言是一种事物与另一种事物沟通的工具：汉语是人和中国人沟通的语言，英语是人和英国人沟通的语言，而**编程语言就是人与计算机沟通的工具**。

类比：古代有人不愿意干活，就让其他人替他干。想让其他人干活，就得用人类的语言告诉他干什么。后来人们想：能不能造一种**机器**替人干活？于是有了最初的计算机——**计算机被造出来的目的，就是帮人工作**。

现在人要让计算机帮忙干活，就不能说人话了，得说**计算机能听懂的话**，这就是编程语言。

- **编程**：人把自己想让计算机做的事情，也就是自己的**思维逻辑**，用编程语言表达出来
- **编程的目的**：让计算机按照人类的思维逻辑去工作，从而**解放人力**

```python
# 用 Python 告诉计算机：把 1 到 100 加起来，并把结果说出来
total = sum(range(1, 101))
print(total)
# 输出: 5050
```

## 1.3 计算机的五大组成部分与三大核心硬件

计算机俗称"电脑"，这个名字包含了人类对它的终极期望：**通电以后能像人脑一样工作**。所以计算机在设计时就是模仿人的功能，由五大部分组成：

| 组成部分 | 作用 | 对应人的功能 |
|---|---|---|
| 控制器（Control Unit） | 计算机的指挥系统 | 大脑 |
| 运算器（ALU） | 数学运算（加减乘除）和逻辑运算 | 大脑 |
| 存储器（Memory） | 计算机的记忆功能，负责数据的存取 | 记忆 |
| 输入设备（Input） | 如键盘、鼠标 | — |
| 输出设备（Output） | 如显示器、扬声器 | — |

**逻辑运算**举例："如果明天是周末，我就不用上班""如果明天是晴天，我就去爬山"——根据条件做判断。

**CPU**：控制器和运算器在计算机里其实是同一个硬件——芯片，也就是 **CPU（中央处理器，Central Processing Unit）**，对应人的大脑。

**存储器**分为内存和外存：

| 对比 | 内存 | 外存（硬盘，如机械硬盘） |
|---|---|---|
| 工作原理 | 基于**电**工作 | 基于**磁**工作 |
| 存取速度 | 很快 | 比内存慢得多 |
| 断电后 | 数据**立即丢失** | 数据**不丢失** |
| 用途 | 临时存取数据 | 永久保存数据 |
| 类比 | 人的记忆（脑子） | 上课记笔记用的笔记本 |

- 买手机时常说的"8 + 128""12 + 512"，说的就是内存和外存的大小
- **受限于技术，目前还没有一种速度和内存一样快、又能永久保存数据的产品**，如果有，就没必要区分了
- 计算机的工作方式和人一样：上课往笔记本里记笔记（存硬盘），考试前把笔记拿出来复习、记到脑子里（使用时先把数据**加载到内存**以提高效率）

**三大核心硬件：CPU、内存、硬盘。**

## 1.4 程序的运行过程：硬盘 → 内存 → CPU

用"买包子"来理解 CPU、内存、硬盘如何配合。假设我是程序员，你是我的计算机，我写一段程序让你去买包子：

```text
第一步：去包子店
第二步：付钱
第三步：把包子拿回来
```

**CPU 下发指令**：这段程序最底层的目的，是控制你的脚跑到包子店、控制你的手掏钱、再拿着包子跑回来。但我的程序里并没有任何"手怎么动、脚怎么动"的详细指令——一定有人做了这件事，那就是你的**大脑**，也就是计算机的 **CPU**。所以程序最终是交给 CPU，由 CPU 去控制其他硬件工作。

**硬盘保存程序**：下次我还想让你买包子，但不想把这三句话再说一遍，就得把程序**存起来**。要永久保存，只能存在硬盘里，也就是你的"小本子"上。

**内存提升效率**：假如只有 CPU 和硬盘，程序其实也能运行——CPU 直接从硬盘取指令执行即可。但 CPU 的速度远远高于硬盘：每次买包子你都掏出小本子，看一步做一步，速度就被**读取过程**拖慢了。也就是说，**IO 操作太慢**，你干活很快，大量时间却浪费在读数据上。为了提升读写速度，就有了内存：先把小本子上的程序**临时记到脑子里**，执行时从记忆里读指令，速度就很快了。**这就是内存存在的意义。**

**总结：程序的运行过程**

```text
① 程序最先存放在硬盘上
② 程序运行时，一定是先把代码从硬盘加载到内存
③ CPU 从内存中读取指令执行
```

例如：你**下载安装** QQ 或游戏，其实就是把别人写好的代码拷贝到你的硬盘上；你**运行** QQ 时，计算机底层发生的事就是：QQ 的代码由硬盘读取到内存，CPU 再从内存取指令执行，程序就运行起来了。

## 1.5 操作系统是什么

假设我要开发一款播放视频的软件，比如B站。播放视频必然要从硬盘读取视频数据，也就必然要**控制硬件**。

要明白一点：**计算机硬件说到底就是一堆废铁，本身不可能自己运行，硬件的一切运行都受软件支配。** 所以要写B站，得先写一个最基本的**控制程序**，让计算机所有的硬件（不只是硬盘）先运行起来，然后才是在控制程序的基础上写B站。

- 像这样的程序称为**应用程序**
- **控制程序的作用：把使用硬件的复杂操作封装成简单的功能，提供给上层的应用程序使用**

控制程序本身十分复杂，需要深入了解硬件最底层的运行原理。这带来两个问题：

1. 如果开发软件要从控制程序写起，可能先得花十年写控制程序，太浪费时间
2. 另一个程序员要写 QQ，也得再写一遍控制程序——大家都在做**重复劳动**

上层应用程序的功能各不相同（QQ 用来聊天，B站用来播放视频），但下层的控制程序基本一致。于是就有专门的公司站出来，把写控制程序这件复杂的事情做了，大家就不用重复劳动了。**这个控制程序就是操作系统（Operating System，OS）**，例如个人常用的 Windows、公司常用的 Linux。

```text
应用程序（B站、QQ、你写的 Python 程序）
        ↓ 调用
操作系统（Windows / Linux）
        ↓ 控制
计算机硬件（CPU、内存、硬盘……）
```

所以我们现在读写数据,其实都是在**跟操作系统打交道**，让操作系统帮我们控制硬盘的读写。

## 1.6 平台与跨平台

应用程序运行时要控制硬件，而控制硬件这件事是交给操作系统完成的。因此：

- **平台（platform）**：**一台运行着操作系统的计算机硬件**就可以称为一个平台。例如"Windows 系统 + 一台华硕电脑"是一个平台，"Linux 系统 + 一台联想电脑"也是一个平台
- **跨平台（cross-platform）**：市面上的硬件和操作系统多种多样，我们写出来的程序最好在任何平台上都能运行，这就叫跨平台

**能否跨平台，是衡量一款程序质量高低的一个非常重要的指标。** 恰好 **Python 的跨平台能力非常强**：在 Windows 电脑上用 Python 写的程序，拿到一台 macOS 电脑上，不用修改就能直接运行。


:::note[补充]
不过如果你的代码里写死了 Windows 风格的路径，或调用了某个系统独有的命令，换到其他系统仍会出错。
:::


## 1.7 x86-64 位与 x86-32 位

下载软件时经常要选择 x86-64 位或 x86-32 位，这是什么意思？

**x86**：Intel 出厂的第一款 CPU 型号叫 8086，后来又有 80286、80386 等一系列型号，大家就把这种型号（架构）的 CPU 统称为 **x86 架构**。现在市面上的 CPU 基本都是 x86 架构。

**二进制**：代码最先存在硬盘上，运行时加载到内存，在此之前计算机会把人写的程序翻译成计算机能看懂的指令，然后 CPU 从内存里取指令运行。计算机基于电工作，只能识别**高电平**和**低电平**两种信号：高电平在逻辑上对应数字 **1**，低电平对应数字 **0**。所以计算机能识别的只有 0101 这样的**二进制**，我们存的数据其实也是一堆二进制。

**位数**：

- **64 位**：CPU 每次从内存里取出 64 个二进制位作为一条指令运行
- **32 位**：CPU 每次从内存里取出 32 个二进制位运行

**向下兼容性**：用车道来类比——64 位 CPU 就像有 64 条车道。

| CPU | 程序每次提供的指令位数 | 能否运行 |
|---|---|---|
| 64 位 | 64 位 | 能 |
| 64 位 | 32 位（64 条车道跑 32 辆车） | 能 |
| 32 位 | 64 位 | **不能**，CPU 处理不了 |

**结论**：**64 位的 CPU 既能运行 64 位程序，也能运行 32 位程序**，反之不行。网上下载的程序标着"x86-32 位"，意味着它支持的是 x86 架构的 CPU，每次向外提供的是一条完整的、不可分割的 32 位指令，作为一个整体交给 CPU 执行。


:::note[补充]
更严格地说，"位数"指 CPU 一次能处理的数据宽度（寄存器宽度）。32 位系统最多寻址 2³² 字节（约 4GB）内存，所以现在的电脑基本都是 64 位，安装软件时选 64 位即可。苹果 M 系列芯片和多数手机用的是 ARM 架构（arm64），与 x86 是不同的指令集。
:::


## 1.8 编程语言的分类

### 1）机器语言（machine language）

计算机能直接理解的是高低电平对应的 0101 二进制指令，**直接用二进制编程**就是机器语言。

- 执行效率**最高**：计算机无障碍理解，直接运行
- 复杂度极高、开发效率极低：写一大堆 0101 才能实现一个很小的功能

### 2）汇编语言（assembly language）

**用一个英文标签代表一组二进制指令**。用汇编输出一句 Hello World 就需要十多行代码。

- 相对机器语言简单一些，执行效率稍低
- 但还是太复杂，开发效率依旧很低

### 3）高级语言（high-level language）

**站在人的角度，用人类的字符编写程序**，更贴近人类语言，人容易理解；但离硬件更远，计算机需要经过翻译最终转换为二进制才能理解。

- 执行效率比前两种低
- 开发效率得到极大提升

高级语言按翻译方式不同又分为两种：

| 类型 | 翻译方式 | 代表 | 执行效率 | 开发效率 | 跨平台性 |
|---|---|---|---|---|---|
| 编译型 | 写完后用**编译器**（类似翻译软件）把完整源代码翻译成机器语言，结果可脱离语言环境独立执行 | C 语言 | 极高 | 相对较低 | 差：针对某一平台编译，结果无法在其他平台使用 |
| 解释型 | 需要**解释器**（类似翻译官），读取代码后**解释一行、执行一行** | Python | 被解释器拖慢 | 极高：发现错误直接改，改完直接运行 | 强：不同平台有各自的解释器，代码可直接运行 |

**总结**：

- 执行效率：机器语言 > 汇编语言 > 高级语言；高级语言中，编译型 > 解释型
- 开发效率：机器语言 < 汇编语言 < 高级语言；高级语言中，编译型 < 解释型
- 解释型语言还具有极强的跨平台性

**Python 为什么火**：现在主流程序都基于网络通信，程序执行效率再高，最终也会被网络延迟拖慢。所以我们主要考虑的是**开发效率和跨平台性**——这正是解释型语言 Python 的长处。


:::note[补充]
严格来说，CPython 会先把 `.py` 源码编译成字节码（bytecode，`__pycache__` 下的 `.pyc` 文件），再由虚拟机逐条执行；但使用体验仍是"写完直接运行"，所以通常归为解释型语言。
:::


## 1.9 Python 环境搭建

### 下载与安装

1. 打开 Python 官网 <https://www.python.org>，把鼠标悬停在 **Downloads** 上选择对应平台（Mac 选 macOS，Windows 选 Windows）
2. **永远不要用最新版本的软件做开发**：最新版本性能不稳定，还可能存在很多 bug。建议选择已经发布了若干修订版的稳定版 Python 3（如 3.11.x、3.12.x）
3. 点击 **Windows x86-64 executable installer**（64 位可执行安装文件）下载

**查看电脑是 32 位还是 64 位**：桌面上"此电脑（我的电脑）"右键 → 属性，即可看到系统类型。如果电脑还是 32 位的，建议换电脑。

**安装步骤（以 Python 3.7 为例）**：

1. 双击安装包，选择 **Customize installation**（自定义安装）
2. 底部暂时不要勾选 "Add Python 3.7 to PATH"（后面会手动配置）
3. 可选功能（其中包含 pip）保持默认，下一步
4. 勾选"为所有用户安装"（Install for all users）
5. 安装路径选 `D:\Python37`（装到任何文件夹都行，不必和课程一样），点 Install，完成后关闭

**安装目录里有什么**：

- **`python.exe`**：这就是安装好的 Python 解释器
- **`Scripts` 文件夹**：里面有 `pip.exe`。pip 用来**安装别人写好的第三方模块**（别人写好的一堆 Python 代码）。写程序讲究开发效率，重复性的功能别人已经写好了，就没必要再写


:::note[补充]
版本号 `3.7.9` 的含义：主版本号 3、次版本号 7、修订号 9。官网访问慢时可用国内镜像，如 `https://mirrors.huaweicloud.com/python/`。
:::


### 在 cmd 中启动解释器

1. 打开终端 cmd：按 Windows 键搜索 `cmd`，或按 `Win + R` 在运行窗口输入 `cmd` 回车
2. 打开后默认所在路径是 `C:\Users\你的用户名`。这个文件夹里没有 python.exe，直接输入 `python.exe` 会提示找不到
3. 切换到解释器所在目录：

```bat
:: 切换盘符：盘符名加冒号
D:
:: 切换目录：cd 空格 文件夹路径
cd D:\Python37
:: 在 Windows 终端里输入 python 和 python.exe 效果一样
python
```

出现 `>>>` 提示符就证明安装成功。输入 `exit()` 回车即可退出——**加括号代表调用一个功能**，这是我们学的第一个 Python 功能：退出。

```text
>>> exit()
```


:::note[补充]
在 Windows 10/11 上，如果 PATH 没有配置好，输入 `python` 可能会弹出 Microsoft Store，这是系统的"应用执行别名"，可在"设置 → 应用 → 高级应用设置 → 应用执行别名"中关闭。也可以用 `python --version` 查看版本号。
:::


## 1.10 环境变量的配置

### 为什么需要环境变量

每次运行解释器都要先 `cd` 切换到对应路径，非常麻烦。怎样才能一打开 cmd 直接敲 `python` 就能运行？于是有了**环境变量（PATH）**，**它里面存的是一堆文件夹路径**。

**查找规则**：输入 `python` 时，操作系统**优先在当前文件夹**里找 python.exe；找不到，再去环境变量 PATH 里的文件夹**从上往下依次检索**。

### 配置步骤（Windows）

1. "此电脑"右键 → 属性 → 高级系统设置 → 环境变量
2. 注意：**不要在上面的"用户变量"里配**（只对当前用户有效），要在下面的**"系统变量"**里配置，这样对所有用户都有效
3. 在系统变量中找到 `Path`，点"编辑"，可以看到里面原本就有一些文件夹路径
4. 复制 Python 解释器的文件夹路径（如 `D:\Python37`），点"新建"粘贴，然后"确定、确定、确定"

此时打开 cmd，当前路径在 `C:\Users\用户名`，找不到 python.exe，操作系统就去 PATH 里从上往下找一遍。`D:\Python37` 被放在最后，是最后一个被检索的文件夹，但一定能找到。输入 `python` 回车，配置成功。

**pip 也要配置环境变量**：pip 以后也会经常用，用同样的套路把 `D:\Python37\Scripts` 加入 PATH，确定后重启 cmd，输入 `pip -V` 即可查看版本信息。


:::note[补充]
可以用 `where python`（Windows）或 `which python3`（Linux/macOS）查看系统实际能找到哪些 python，排在最前面的那个生效。修改环境变量后必须重新打开 cmd 才会生效。
:::


## 1.11 实现 Python 多版本共存

如果想在同一台电脑上安装 Python 2.7 和 Python 3.7 两个版本，并让它们都能使用，该怎么做？

按上一节的方法，假设把 `D:\Python27` 和 `D:\Python37` 依次加入 PATH，重新打开 cmd 输入 `python`——结果进入的却是 **Python 2.7**！

**原因**：输入 `python` 后，操作系统先在当前路径找，找不到就按 PATH **从上往下**找，先在 `D:\Python27` 找到了 python.exe，就用了它。而 `Python27` 和 `Python37` 里的文件**都叫 python.exe**。如果把 `Python37` 的路径调到上面，每次都能用 Python 3，但 Python 2 又用不了了。

**解决方法：参考 pip 的做法。** pip 就是把同一个文件复制了几份，分别命名为 pip、pip3、pip3.7。照着做：

1. 在 `D:\Python37` 中把 `python.exe` **复制一份**，重命名为 `python3.exe`
2. 在 `D:\Python27` 中把 `python.exe` 复制一份，重命名为 `python2.exe`
3. 以后在 cmd 中输入 `python2` 就是让操作系统执行 python2.exe，输入 `python3` 就只会执行 python3.exe


:::warning[注意]
要"复制后重命名"，不要直接重命名原文件，否则 pip 等工具可能找不到解释器。
:::



:::tip[Windows py 启动器]
Windows 版 Python 还自带 `py` 启动器：`py -0` 列出已安装版本，`py -3.7` / `py -2.7` 启动指定版本。更专业的做法是使用虚拟环境（`python -m venv venv`），让每个项目拥有独立的解释器副本和第三方库。
:::


## 1.12 运行 Python 代码的两种方式

### 方式一：交互式环境

在 cmd 中输入 `python3`，进入 Python 的交互式界面，写第一行程序：

```text
>>> print("hello world")
hello world
```

**注意：Python 中输入的所有符号都必须是英文状态下的符号**，输入中文符号会直接报错。

- 为什么叫"交互式"：输入一行代码回车，立刻就能看到运行结果
- 好处：即时得到结果，一般用于**测试某一行代码的功能**
- 缺点：写的代码**不能保存**，所以多数情况下不在这里写代码

### 方式二：把代码写进文件执行

程序肯定要永久保存，所以要把代码写进文件、存在硬盘里，再用解释器解释执行其中的内容。

1. 在桌面新建一个文本文档，写入 `print("hello world")` 并保存
2. 在 cmd 中切换到桌面路径（默认在 `C:\Users\用户名`，直接 `cd Desktop` 即可；输入文件夹开头按 **Tab 键**可自动补全）
3. 输入 `python3 文件名` 回车运行

```bat
cd Desktop
python3 新建文本文档.txt
```

也可以不切换目录：输入 `python3 ` 后把文件**拖拽**到终端窗口，会自动填入文件的完整路径，回车同样能执行。

**文件后缀名对运行没有任何影响**：Python 程序是解释执行的，解释器打开文件、读入内容再解释执行，只要内容符合 Python 语法就能运行，和后缀名无关（上面运行的就是 `.txt`）。但**从规范上讲，Python 文件应以 `.py` 结尾**。

```python
# hello.py —— 第一个 Python 程序文件
print("hello world")
# 输出: hello world
```


:::note[补充]
交互式下直接输入表达式（如 `1 + 2`）会自动显示结果；文件中只写 `1 + 2` 不会有任何输出，必须用 `print()`。
:::


## 1.13 集成开发环境（IDE）

用普通文本编辑器写代码没问题，但它的功能太单一：

- 代码有语法错误时没有提示
- 保存后还要打开终端、输入解释器和文件路径才能运行，结果也只能在终端里看

于是有了这样一种编辑器：能在里面创建文件；写代码出现语法错误会提示；有**自动补全**功能，大幅提升开发效率；运行程序时**自动调用 Python 解释器**，并把结果显示在编辑器里。这就是**集成开发环境（Integrated Development Environment，IDE）**。

Python 开发推荐的 IDE 是 **PyCharm**：

1. 搜索 PyCharm 进入官网，点击下载
2. PyCharm 有两个版本：**Professional（专业版）** 功能多但收费；**Community（社区版）** 免费但功能少。
3. Mac 用户选择 Mac 版下载，Windows 用户下载 Windows 版
4. 安装很简单，一路"下一步"即可


:::note[补充]
1.常见的 Python 开发工具还有 VS Code（编者使用，轻量免费，装 Python 插件后体验接近 IDE，且安装插件后支持其他语言开发）
2. Jupyter Notebook（适合数据分析）
3. IDLE（Python 自带的简易 IDE）。
4. 较新版本的 PyCharm 已合并为统一安装包，未订阅专业功能时可免费使用核心功能，学习基础完全够用。
:::


### 新建项目并运行

1. 点击 **New Project**，新建项目其实就是**新建一个文件夹**，指定文件夹路径和名字
2. 为项目指定 Python 解释器：
   - **New Environment**：创建新的虚拟环境（暂时不管，后面用到再说）
   - **Existing Interpreter**：选择已存在的解释器。点右侧"…"，选择 **System Interpreter**（装在系统里的解释器），PyCharm 已自动找到 Python 3.7 和 Python 2.7；如果没有，就点"…"手动找到 Python 安装路径
3. 选 Python 3.7，OK，点击 Create

创建项目后：

1. PyCharm 默认创建的文件（main.py）不用，右键 Delete 删掉
2. 在项目文件夹上右键 → **New → Python File**，取名 `test`，回车
3. 调大字体：菜单栏 **File → Settings → Editor** 中调整代码字体大小
4. 写一行代码：

```python
# test.py
print("Hello Python")
# 输出: Hello Python
```

体会 IDE 的便利：

- **自动补全**：输入 `print` 的开头就会提示，按 Tab 键自动补全；输入前引号，后引号也自动补上
- **语法错误提示**：把括号删掉或改成中文括号，会立刻出现**红色波浪线**
- **自动保存**：不需要自己保存

在编辑区右键 → **Run 'test'**（快捷键 `Ctrl + Shift + F10`），可以看到 PyCharm 调用了 Python 3.7 解释器运行程序，结果显示在当前界面下方。

### 切换解释器

如果想用 Python 2.7 运行：**File → Settings → Project → Python Interpreter**，点齿轮图标 → Add，选择 System Interpreter，找到 Python 2.7（没有就点"…"手动添加），OK、OK。再运行，调用的就是 Python 2.7。课程后续换回 Python 3.7。


:::tip[常用快捷键]
- `Ctrl + /` 注释/取消注释
- `Ctrl + D` 复制当前行
- `Ctrl + Alt + L` 格式化代码
:::


## 1.14 写代码记得注释

**注释（comment）就是对代码的解释说明。** 写了一段关键代码实现某个功能，就可以在前面写注释，让别人读你代码时能读懂——以后代码可能交给别人维护，别人读懂了才能维护。

### 单行注释：`#`

先写一个 `#`，后面写注释信息；也可以写在代码的后面。注释的内容不会被执行。某行代码暂时不想执行，也可以在前面加 `#` 把它注释掉。

```python
# 这段代码实现了打印问候语的功能
print("hello")  # 注释也可以写在代码后面
# print("这一行被注释掉了，不会执行")
# 输出: hello
```

**注释规范**：在 PyCharm 中，不规范的写法会出现**黄色波浪线**——这是提示你没有遵循 Python 的语法规范，**不是语法错误**（语法错误是红色波浪线），程序能正常运行，但显得不专业。正确的规范：

- 在代码后面写注释时，代码与 `#` 之间**空两格**
- `#` 后面**空一格**再写内容

### 多行注释：三引号

用三个单引号 `'''` 或三个双引号 `"""`，中间可以写多行注释，不影响程序运行。一段代码暂时都不想执行，也可以用三引号把它包起来。

```python
"""
这是多行注释，
可以写很多行。
"""

'''
print("这段代码被三引号包起来，暂时不执行")
'''

print("多行注释不会影响程序运行")
# 输出: 多行注释不会影响程序运行
```

### 养成写注释的习惯

- 不管给别人还是给自己写代码，一定要养成写注释的习惯，否则过十天半个月，自己都不容易读懂自己的代码
- 但**不是每行都加注释**，那样会显得程序很乱，**给关键性的代码写注释**即可
- 如果写的是开源软件（如发布到 GitHub 上供别人使用），别人可能直接集成到商业项目里，尤其要把**提供给别人用的功能**的注释写详细


:::note[PEP 8]
Python 的代码风格规范叫 **PEP 8**，上面"空两格、空一格"的要求就出自这里。严格来说，三引号"多行注释"其实是一个没有被使用的字符串；写在函数开头时会成为函数的文档字符串（docstring）。
:::


## 本章小结

- 学不学 Python 要理性判断：排行榜世界第一、多省纳入高考与中小学课程，意味着国家在储备人才。
- 编程语言是人与计算机沟通的工具；编程就是把思维逻辑用编程语言表达出来，目的是解放人力。
- 五大组成部分：控制器、运算器（合为 CPU）、存储器、输入设备、输出设备；重点掌握 CPU、内存、硬盘。
- 内存基于电，快但断电丢失；硬盘基于磁，慢但永久保存。
- 程序存在硬盘 → 运行时加载到内存 → CPU 从内存取指令执行；内存的意义是减少慢速 IO。
- 操作系统是把硬件复杂操作封装成简单功能、供应用程序调用的控制程序。
- 平台 = 操作系统 + 硬件；跨平台是衡量程序质量的重要指标，Python 跨平台能力强。
- 64 位 CPU 每次取 64 位指令，向下兼容 32 位程序。
- 执行效率：机器 > 汇编 > 高级（编译型 > 解释型）；开发效率相反；网络时代更看重开发效率和跨平台，所以 Python 火。
- 从 python.org 下载安装包，不要用最新版做开发；`python.exe` 是解释器，`Scripts` 里的 pip 用于安装第三方模块。
- 环境变量 PATH 存的是文件夹路径：系统先找当前文件夹，再按 PATH 从上往下找；在"系统变量"中配置。
- 多版本共存：复制 python.exe 并重命名为 python2.exe / python3.exe，Scripts 目录也加入 PATH。
- 运行方式：交互式（即时看结果、不能保存，用于测试）与文件式（`python3 文件路径`）；后缀名不影响运行，规范用 `.py`。
- IDE 集成了编辑、提示、补全、运行等功能；PyCharm 新建项目要指定解释器，可随时切换。
- 注释：单行 `#`（代码后空两格、`#` 后空一格），多行用三引号；关键代码写注释，开源功能写详细。

## 练习

1. 内存和硬盘在工作原理、速度、断电表现上有什么区别？分别对应人的什么？
2. 用"买包子"的例子说明：如果计算机没有内存，程序还能运行吗？为什么还需要内存？
3. 一款标着"x86-64 位"的软件能否在 32 位 CPU 上运行？标着"x86-32 位"的软件能否在 64 位 CPU 上运行？
4. 编译型语言和解释型语言有什么区别？为什么说网络时代 Python 更有优势？
5. 已把 `D:\Python27` 和 `D:\Python37` 依次加入 PATH，在 cmd 输入 `python` 却进入 Python 2.7，为什么？怎样做才能让 `python2`、`python3` 分别启动两个版本？

<details><summary>参考答案</summary>

1. 内存基于电工作，存取快，断电数据立即丢失，对应人的记忆；硬盘基于磁工作，存取慢得多，断电数据不丢失，对应记笔记的笔记本。
2. 能运行，CPU 可以直接从硬盘取指令执行；但 CPU 速度远高于硬盘，每次都从硬盘读指令（相当于每一步都翻小本子），大量时间浪费在 IO 上。先把程序加载到内存，CPU 从内存读指令，速度就快多了。
3. 不能，32 位 CPU 每次只能接收 32 位指令，处理不了 64 位指令；能，CPU 具有向下兼容性，64 位 CPU 可以运行 32 位程序。
4. 编译型语言用编译器把完整源代码一次翻译成机器语言，可独立执行、效率极高，但开发效率较低，且编译结果只能在对应平台使用；解释型语言由解释器解释一行执行一行，执行效率较低，但开发效率极高、跨平台性强。网络时代程序执行再快也会被网络延迟拖慢，所以开发效率和跨平台性更重要，这正是 Python 的优势。
5. 操作系统在当前目录找不到 python.exe 时，按 PATH 从上往下查找，先在 `D:\Python27` 找到了 python.exe。解决：在 `D:\Python27` 中复制 python.exe 并重命名为 python2.exe，在 `D:\Python37` 中复制并重命名为 python3.exe，之后输入 `python2` / `python3` 即可分别启动。

</details>
